独立 `audit_data.py` 检查全1672行：α、n及配对光谱均无完全相同的不同ID；TRAIN/CAL/PRED之间无重复record/physical ID。有限抽取23,944对，没有构造全配对矩阵。α与n各有8及10对Pearson相关≥0.999，均无≥0.9999；满足“相对RMS≤1%且相关≥0.999”的有4对，全部仅n满足，另存逐ID表。高相关的平滑谱不等于重复实物，抽样也不能排除全部近重复。

全部18个来源组都在三个角色中出现；1672条实际batch_id均未填写。原ZY组各一声明批次，新增组批次数未知。因此材料100%/97.64%等历史分数仍是已代表来源中的内部样品划分结果，不能借无ID重合而排除批次、制样和仪器混杂。四个枣仁来源各仅1份PRED，其中三个来源也仅1份TRAIN，普通分层来源调参不可用。
