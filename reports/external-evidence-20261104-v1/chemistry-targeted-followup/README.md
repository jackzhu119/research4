## 对当前PySCF工作的意义

先完成同一真实构象的Hessian、3N−6模式及虚频检查，再报告该构象的孤立分子振动。没有合格纯品低频参照时，只讨论振型和理论—实验范围差异；不能由频率接近确认1.08、1.13–1.14、1.18–1.19或1.28–1.30 THz的化学归属。固态药材还存在氢键、晶格和分子间集体振动，SERS与IR的选律及基底效应也不同。
