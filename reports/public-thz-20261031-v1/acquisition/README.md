### 水果论文与版本必须分开

GitHub原件 `CITATION.cff` 指定 DOI `10.1145/3625687.3625815`（SenSys 2023）。同团队后续 Nature Food 论文 DOI `10.1038/s43016-024-01083-x` 的正式处理后数据位于 Figshare `10.6084/m9.figshare.27299859.v1`。其网页明确标注CC BY 4.0、下载包265.05 kB，但这份Figshare文件本轮下载受阻。不能未经比对把两个来源称为同一数据队列，也不能把Figshare许可自动套到较早GitHub原件。

水果与酸枣仁的物理测量方式不同。即使水果辅助回归能够运行，也只证明另一个任务上的方法表现，不能证明酸枣仁来源识别准确率得到提升。

## 排除与证据边界

`source_catalog.csv/json` 共记录16个候选与排除项。另一个Nature Food同名GitHub仓库实为12张JPG、视频和设备占位文件，不含可训练数值样本；MSFAN的CSV是聚合物；部分“THz”工程仓库是合成信号；Rice HSI不等于THz。均未计入本轮植物分类新增队列。

2023年CascadeSeed论文的3378粒水稻是文献样本数，其原始谱和代码需要向通讯作者索取；补充材料中的图片和代谢物表不等于原始THz训练数据。本文只记录公开说明，没有代用户发送邮件。

本轮叶片数值审查命令：

```bash
python scripts/acquire_public_plant_thz_20261031.py
python scripts/audit_acquired_leaf_curves_20261031.py
```

叶片脚本只读取文本数字、不执行TeX；`leaf_numeric_curve_inventory.csv` 把每条曲线与文件、物理量、日次、频率点数关联。所有记录显式标注独立样品单位未建立。没有为这些不合格队列生成虚假准确率。
