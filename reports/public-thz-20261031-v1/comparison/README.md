# 公开太赫兹数据：冻结协议内的回顾性结果

本目录由独立只读导出器在评分完成且获得 root 绑定哈希的导出许可后生成；不进行训练、再次评分或模型选择。

## 解释边界

- 酸枣仁历史 R2：821/855＝96.0234%，保持为原研究强基线。它仅出现在历史背景表，不能与人参/水果成绩相减作为准确率提升。
- 人参为42片、物种二分类，0西洋参/1人参；六个导出文件组留一外层、五个剩余文件组内层。原料根与批次对应仍未知，文件组不是独立生物批次。全部42/43/44种子均列出；均值±样本标准差描述种子波动，不是置信区间。
- R0→R1→R2→R3→R4是源内选择策略的对照，不能因外层某阶段较好而倒选配置；最终表中的最好分数也只属于回顾性描述，不构成新独立确认。准确率提升仅在相同人参协议与相同种子内相对R0计算，个百分点与相对百分比不同。
- 水果分别为芒果Brix/DM、梨Brix、柿Brix四项回归；每任务40时点观察来自10个持续跟踪果实，外5/内3按果实分组。报告RMSE、MAE和R²，保留负R²，不能称为分类准确率。标签为原Excel读数，物理单位/测定方法未确认。其128个时域工程块不等于吸收系数或THz频率轴。
- 水果原件、逐样本标签/预测、波形、模型和支持向量因许可不明保留本地；本目录只含聚合指标、参数和统计图。未复制逐样本数据。

## 文件和统计口径

CSV与XLSX提供人参各方法逐种子/均值±标准差、四轮提升、混淆矩阵、选参、输入特征数、描述性Jaccard稳定性和计算开销，以及水果聚合回归对照。PNG/PDF为独立图件。

特征稳定性只比较同一表示中的原始输入列集合；全谱的Jaccard=1是平凡结果。PCA潜变量维数另见参数，不能把输入列数写成最终潜在维数。不同预处理下的列重合不是化学峰归属或跨批次稳定性证明。

计算时间汇总实际trial记录，含部分变换、预测、序列化及共享缓存影响，不是纯fit耗时或端到端墙钟。source_search计全部实际内层模型，outer_unique_models只计真实拟合对象；角色别名复用不能重复宣称实际拟合次数。查询分数不参与成本或参数选择。

`export_manifest.json`绑定源评分/预测锁与本次导出许可；`files_sha256.json`提供产物哈希。原始失败数保留于来源记录，未隐藏失败或挑选有利种子。
