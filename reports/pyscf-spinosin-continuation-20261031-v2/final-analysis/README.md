本目录只读重算保存梯度统计与Hessian正常模式，不启动SCF、梯度或Hessian导数计算。

实际配对几何评估37条，水通过频率9条，斯皮诺素通过频率0条。多后端水记录不是不同分子。

computed_frequencies_including_unvalidated.csv保留未通过极小点／正频率检查的真实计算频率，不能据此作峰归属；未计算则只保留表头。NOT_RUN不等于零吸收或不存在低频模式。

已结束但没有result.json的原生进程以父进程真实退出记录和原样input／progress快照派生PARTIAL，明确worker_result_missing；不向计算目录补造result.json。快照中的频率完成声明没有最终结果时一律不获得验证资格，已有Hessian／缓存文件仅作为实际部分执行证据，不能代替完成频率计算。详见missing_worker_result_audit.json。

所有模式图只用实际频率分析的完整精度几何；箭头／动画幅度任意缩放，不是热运动幅度或IR强度。IR均NOT_COMPUTED，频率位置不代表吸收强度。全部实验候选与全部合格范围内模式作笛卡尔对照，不按接近程度挑构象或计算方法。

孤立分子模式不包括固态晶格、集体振动与复杂基质。频率接近不能确认药材的化学归属，需要纯品／含量测定等证据。本次不修改96.0234%分类模型。
