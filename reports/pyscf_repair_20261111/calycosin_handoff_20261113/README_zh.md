## 文件与读取

- `completed_points_90.csv`：90 行位移点，包含步长、坐标索引、符号、能量、3 个偶极分量、99 个核梯度分量，以及严格 SCF 设置、fresh 残差核查、电子数误差与核梯度 RMS/最大值。核梯度描述当前位移点的导数大小，不是其应满足平衡几何阈值的断言。
- `points/h0/`：90 个点原始 result/input JSON 与 gradient/dipole/coordinates NPY，按原字节保存。原始 JSON 中绝对路径为来源记录；离线读取时使用本包对应相对路径。逐点密度矩阵及大型日志、缓存未打包；JSON 可能引用这些未包含来源文件。
- `optimized_grid5/`：已完成的严格 grid5 优化结果、最终中心点审计、Bohr 坐标、Angstrom XYZ、偶极与梯度；仅包含一个最终密度矩阵 `final_density_restart.npy`（用于将来明确授权后重启）。优化器收敛和核驻点条件已通过，但没有完整 Hessian，因此不据此证明无虚频或全局最低点。
- `partial_hessian_columns_99x45.npy/.csv`：仅保存已有 45 列，每列由 (g+ − g−)/(2h) 得到，单位 Hartree/Bohr²。不是完整方阵，也未补零、外推或对称化。
- `partial_dipole_derivatives_3x45.npy/.csv`：同样 45 列的 (μ+ − μ−)/(2h)，单位原子偶极单位/Bohr。
- `valid_column_indices.json`：显式列索引、形状、单位与缺失范围。全部索引为零起始，原子优先展平顺序 x,y,z。
- `source_provenance.json`：每份原始复制文件的来源路径、字节数与 SHA-256。`manifest_sha256.json` 覆盖包内其余所有文件；清单自身哈希由外部 ZIP 整体哈希保护，避免自引用。
- `verification.json`：点数、数组哈希、严格电子条件、位移几何和有限差分一致性核验。

方法为 PBE/def2-SVP、原生 grid5、无显式色散、无密度拟合；详细设置以原始 JSON 为准。XYZ 转换使用 1 Bohr = 0.529177210903 Å。包内没有分类器结果。
