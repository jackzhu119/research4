68/68个模态表均实际读取、CRC通过，并按明确样品编号严格配对：
吸收系数2578点、折射率2578点、时域6750点、频域1001点。完整数值NPZ保存所有模态和参考列。
紧凑Excel只去除原件样式/空白范围，未按模型结果挑选或删除样品；Excel数字串重写可能出现
机器浮点精度级别的往返差，后续算法优先使用保存原始解析float64的NPZ。

负值如实保留：时域的正负振幅、频域负值和全频段吸收系数负估计均未剪裁；TM03的47个
负折射率估计也保留并标记统计。它们不被自动解释为化学吸收峰。绝对吸收系数单位仍未获
原始仪器/方法说明核验，跨植物任务属于谱形工程探索。

## 拆分与实验边界

本次入库本身没有模型拟合。后续应由独立、固定协议按entity_id拆为训练/校准/预测；
