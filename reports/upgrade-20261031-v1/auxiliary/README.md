主任务仍是酸枣仁识别；本附属任务不更改酸枣仁数据、分区、最强 MC-UVE＋SVM 候选或任何历史结果。

用户在本轮明确回复“**不存在重复扫描和重新压片，是单独的**”。本次以追加 annotation／overlay 登记黄芪403份、天麻405份为用户声明独立样品；此声明不是实验室核验，也没有提供多个采集批次。原数据库资格快照原样保留，最新资格应叠加 [声明](../../../data/annotations/huangqi_tianma_user_declaration_20261031.json) 与 [overlay](../../../data/multiplant_database/metadata/user_declaration_overlays/20261031_huangqi_tianma_v1/overlay_manifest.json) 阅读。

分别构建 HQ01—HQ04 与 TM01—TM04 的四文件来源组任务，不能混合两植物同号标签，也不能宣称文件名所述城市已外部验证为真实生长地。上游材料、制样／采集批次、仪器、物理量单位仍未核实，跨植物迁移保持 BLOCKED。

## 预设候选与可用模态

每植物5外折／2内折、split seed20261031；训练seed42、43、44全部保留。

- full SNV SVM：C=1、10；gamma=scale、0.1×scale，共4候选。
- MC-UVE＋SVM：MC10/LV1/10%与MC20/LV2/20%各配上述4组SVM，共8候选。
- CNN、ResNet1D、SE、双表示融合：各有相同12／24轮小预算档位；另保留只用内层成绩选择神经家族的策略别名，无额外拟合。
- 黄芪融合使用全403份可配对的时域＋频域。甘肃n整类缺失，α＋n四类任务BLOCKED。
- 天麻融合使用全405份可配对的α＋n。贵州／安徽time不可读，四表示任务BLOCKED。

所有模型在固定样品分区上对比。融合模态与α单支同时发生变化，当前没有对应单time／单frequency或单n的完整辅助消融，不能把差异全部归因为融合结构。SVM三seed无概率拟合通常产生相同预测，只作重复种子敏感性记录，不能算3组独立样本或研究。
