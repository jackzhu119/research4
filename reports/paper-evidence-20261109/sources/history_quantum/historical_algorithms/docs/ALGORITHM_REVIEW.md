## 结论

最值得作为起点的是 **PLS/SVM + 正确的光谱预处理 + CARS/MC-UVE 的训练内变量选择**。第一项中药课题优先考虑黄芪产地鉴别；在补齐化学实测值后，再开展指定成分的定量预测。更有实用意义的待验证改进是：**在不同批次中稳定的频段选择，以及目标批次少量独立样品的校准**。

这些都是研究假设，尚未证明优于现有方法，也不能以算法组合、换药材或更换群智能优化器本身主张方法创新。原论文和源码作者需要保留引用；新工程实现、实验设计和经验证的改进可以构成自己的工作。

## 逐项问题及处理优先级

### 1. CARS（sy）的误差输出有未说明的缩放：高优先级

位置：`CARS（sy）.rar → CARS/carspls.m` 第 88、90 行：

```matlab
F.cv=RMSEP/2.8;
F.minRMSECV=Rmin/2.8;
```

该程序先用未缩放误差选择变量集合，之后把报告字段缩小 2.8 倍；`plotcars.m` 第 8、19 行又把该字段画成 RMSECV。因此变量集合不因这个统一常数而改变，但报告的误差不再是前面计算的原始 RMSECV。源码中未给出相应的目标单位换算依据。恢复原值，并在新的独立评价集上重新计算指标；不能把这种缩放解释为模型性能提高。

同文件第 93 行写入 `Ft.ratio` 而不是输出结构 `F.ratio`；`plotcars.m` 的首函数名为 `plotmars`。需要一并整理接口，但这些接口问题与统计有效性问题应分别处理。

### 2. 两份 CARS 并不是同一默认算法

- `0308 CARS+UVE.rar → carspls.m` 第 37–39、63–85 行：默认 `originalVersion=0`、`selectLV=1`。默认用全部校正数据计算系数，并按非零权重保留变量；原始随机重采样分支需要显式设为 1。
- `CARS（sy）.rar → carspls.m` 第 42–59 行：每次随机取约 90% 样本，按绝对 PLS 系数加权重采样。
- 两者都根据 PLS 回归系数建立筛选路径，再用 CV 选择子集。路径建立本身已经使用 y；筛完变量之后再做一次普通 CV，不会自动消除选择偏差。筛选器必须在每个外层/内层训练分区重新拟合。
- 对多产地分类，不能把无序产地编码 1、2、3、4 后直接当连续含量喂给单输出回归版 CARS；应使用适配多分类的目标或分类筛选方法，并检查编码置换不变性。

### 3. UVE 与 MC-UVE 的行为需要区分

- `0308 CARS+UVE.rar → uvepls.m` 第 25、28–38 行：加入微小随机噪声变量，通过 jackknife 系数稳定性与噪声变量阈值比较筛选，是噪声参照 UVE。
- 同文件第 21 行强制 `pZ=px`，覆盖调用者的噪声变量数；第 22–23 行用时钟重新设随机种子，外部设置种子无法保证复现。传入的 `fold` 没有参与实际划分，默认 `nxvals=n`，不能把参数 `5` 简单解释成五折运行。
- `UVE.zip → uve/mcuvepls.m` 第 32–35 行使用 `RI=U./SD` 并按有符号 RI 排序；`0308` 版本第 32–34 行使用 `abs(U./SD)`。若按排名截取变量，稳定且强的负系数变量在前者可能被排到末尾。应明确使用绝对稳定性，给零方差设置可解释处理，并在训练内选择保留数量。
- MC-UVE 这些实现返回稳定性/排序，不都返回自动确定的最终变量集合。保留多少变量仍是需要训练内调节的超参数。
- `UVE.zip → plslda.m` 第 4 行注明二分类 ±1；不能直接用四个整数产地作为它的原始标签。
- `demo_PLS_Discriminant_Analysis.m` 调用 `carsplslda/plotcars_plslda`，`demo_PLS_Regression.m` 调用 `plotmcuvepls`；在本次检查的压缩包中没有找到这些函数，示例入口不能据此认定为完整可运行。

### 4. SSA-SVM 的最终分数重复使用了寻优折：高优先级

位置：`麻雀算法优化SVM-沈-2021-0802.zip → SSA_SVM_main.m`。

- 第 29–30、271–278 行：SSA 的适应度直接来自 `KfoldIndex` 对应 CV 分类误差。
- 第 49–62 行：使用寻优得到的参数，再对同一 `KfoldIndex` 报准确率。

这是参数选择后的重复使用分数，不能作为独立泛化性能。应在外层留出独立样品/批次，SSA 只访问外层训练区里的内层 CV。对比方法必须使用相同的核、搜索范围、预处理、数据分区和模型训练次数预算。替换 SSA 名称或增加种群迭代不构成已经证实的科研改进。

该程序 `max_min_scale` 是逐条光谱 min–max，不是用全体样本统计量做特征缩放；不能仅因它位于 CV 外就断言跨样本泄漏。但它可能去掉与含量有关的绝对幅值，且缺少常量谱分母为零的保护。

小麦筋度稿件提到按种群适应度引入“自适应变异”。本包 SSA 主循环（第 117–188 行）未识别出该描述对应的显式变异概率/幅度控制，不能仅因文件名相近就断言这份源码完整实现了稿件的改进版 SSA；需与作者确认版本。

### 5. 独立 PLS 文本有明确的测试集信息混入

位置：`PLS.txt` 与 `PLS-Prediction-shenyin.txt` 第 21–35 行（相同流程）：合并 `X` 与 `x`、`Y` 与 `y`，共同计算归一化范围。测试输入与测试目标均参与了变换参数确定。

此外，分别对 X 和 y 做 PCA 再回归，与标准 PLS 的联合潜变量提取不同。建议以 sklearn 的 `PLSRegression` 或 MATLAB `plsregress` 重建清晰基线，所有变换在训练分区拟合；潜变量数通过内层分组 CV 选择。`PLS1.txt` 使用真正的 `plsregress`，但当前仅展示全数据拟合结果，仍缺独立验证。

### 6. CNN 是人工二维重排，且当前中药数据不能直接代入

- `cnn_4.txt` 第 7–13 行及压缩包 `cnn_v2/cnn_v21.m`：固定补 17 个零再 `reshape(...,32,32,1)`，隐含原特征数恰为 1007。
- 当前吸收系数每条光谱有 2578 个频率点；示例的 0.1–1.5 THz 区间也有 612 个点，均不满足 `p+17=1024`。
- 人工折成图像引入了不对应真实频率距离的二维邻接；优先比较保留频率顺序的轻量 1D-CNN，并报告参数量及学习曲线。
- `cnn_4.txt` 第 68 行、`cnn_v21.m` 第 76 行把 `XTest,YTest` 作为 `ValidationData`，最后又在同一集合评价。该设置本身不能证明测试标签更新了网络权重；但若据验证曲线选模型/参数/轮数，这个集合就不能再作为独立测试集。
- `floor(numel(YTrain)/128)` 在训练样本少于 128 时为 0，需要检查验证频率；类别数也应从经核验的标签推导。

### 7. PCA-Kmeans 的测试投影与标签解释有问题

位置：`main.txt` 第 74、122 行，压缩包 `main0627.m` 第 68、114–118 行。

MATLAB `pca(X)` 的训练分数使用中心化后的 X。测试端直接 `pn_test*PCALoadings` 未减去训练均值，与训练分数坐标不一致，应使用保存的训练均值。聚类编号本身无监督、可任意置换，不能直接把编号等同于产地；若学习簇到类别的映射，只能用训练标签确定。

### 8. 多个工具箱的同名函数会互相覆盖

三个包中的 `pls.m`、`mcuvepls.m`、`pretreat.m` 等具有不同接口或输出结构。例如 `0308` 的 MC-UVE 读 `PLS.coef_origin`，`UVE.zip` 版本读 `PLS.regcoef_pretreat`。将所有解压目录一起 `addpath(genpath(...))` 可能调用到不匹配的版本。

每个复现实验固定一个工具箱版本，用 `which -all pls plsnipals pretreat mcuvepls` 核对解析路径；迁移时采用明确的模块命名与接口，不以覆盖全局搜索路径组合工具箱。

### 9. 部分示例的依赖和数据语义不能沿用

- `LSSVM.txt` 需要 `trainlssvm`。检查的材料有部分 `simlssvm`，没有找到完整训练入口及 `initlssvm`，不能把 LS-SVM 示例视为自包含软件。SVM、SVR 与 LS-SVM 也不能混用名称。
- SSA 包提供 `.mexw64/.dll/.exe`，属于 Windows 二进制；不能直接在当前 Linux 环境执行，也不能据二进制文件存在推断工具箱兼容。
- `spectralprocessing.m` 第 106–111 行联合归一化训练/测试输入；第 113 行 LIBSVM 入参顺序与本包其他调用不一致；第 124 行使用的 `pre` 仅在已注释语句中赋值。这是需要逐段清理的拼接示例。
- `syqpcx程序(1).txt` 第 92–93 行分别抽取 `2:91` 与 `2:92`（90 与 91 列），第 183 行直接纵向拼接会维数不一致；大量路径与第 300 行索引均写死。
- `特征提取.docx` 的 `Texture` 假定 256×256 图像，灰度输入缺少 `Gray` 赋值分支；文档抽取出的若干 `if` 条件不完整。代码中的 `deltaX/deltaY` 累积的是方差，相关系数分母却直接相乘，需要按标准差核对。首轮一维光谱研究不应混入这些图像变量。
- `平滑曲线.txt` 对读入矩阵每列平滑；若第一列是频率/时间坐标，也会被当成信号处理。新的数据接口应显式分离坐标、参考值、样本谱。

## 来源、软件角色与复用方式

CARS 文件头明确给出 Hongdong Li 等人的来源及 2009 年 Analytica Chimica Acta 648:77–84 文献；多处代码保留 H.D. Li、Massart 团队等说明。LIBSVM 有独立 `COPYRIGHT`，部分 `newff/princomp` 文件有 MathWorks 版权说明。获得资料不等同于这些基础方法变成自己的原创；实际复用要保留已有来源及适用的许可说明。

GaussView 安装包是计算化学可视化软件资料，不是光谱分类/定量训练算法。是否具有 Gaussian 等计算引擎、可用许可及对应实验需求尚未确认。即使开展分子振动模拟，也只能辅助解释，不能替代中药真实样品的含量标定与外部测试。

## 现阶段的算法取舍

| 优先级 | 研究模块 | 本次判断 |
| --- | --- | --- |
| 先做 | SNV/原谱 + SVM；定量 PLS/SVR | 简洁、可核查，建立可信参照 |
| 第二步 | 修正 CARS、MC-UVE，比较连续频段与选择稳定性 | 有明确的现有源码基础；必须在训练内重选变量 |
| 第三步 | 分组重采样的频段稳定性、跨批次少量样本校准 | 有价值的待验证改进；需补跨批次和独立样品元数据 |
| 对照 | SSA-SVM vs 同预算随机/网格搜索 | 判断优化器是否实际带来增益 |
| 有足够独立样本后 | 轻量 1D-CNN、冻结编码器后校准分类头 | 不能仅以扫描次数支撑深度网络样本量 |
| 有真实图像后 | GLCM/Sobel/图像-光谱融合 | 当前一维频谱不能充当真实空间图像 |

本次新增 Python 代码只实现数据读取、SVC/SVR/PLS 嵌套分组验证与 support/query 划分基础设施。没有把上述待验证改进宣称为已实现、已发表或已取得更高准确率。
