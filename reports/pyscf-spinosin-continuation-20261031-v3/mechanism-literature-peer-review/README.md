S01的独立主来源是[官方PubMed摘要](https://pubmed.ncbi.nlm.nih.gov/36720435/)。本篇摘要确实支持代表成分依据；出版商搜索页混排的2025药典或推荐文章信息不能并入这篇2023综述的结论。药材质量标志与本项目的匿名来源分类标志必须区分。

S04的[官方摘要](https://pubmed.ncbi.nlm.nih.gov/35735354/)支持一般数值积分风险。它说增大网格有时能够缓解问题，并非所有情况下都能解决。因此“开展网格／收敛敏感性检查”应写为本项目据此提出的方法检查，而不是已经测得当前PBE/grid1存在某个特定偏差。保留小频率和虚频的不确定性同样属于本项目的审慎处理规则，不能写成该摘要已验证的专门流程。

S06的静态复核确认输出键为`freq_error`、`freq_au`、`freq_wavenumber`、`norm_mode`、`reduced_mass`、`vib_temperature`、`force_const_au`、`force_const_dyne`，函数保留`#TODO: IR intensity`。未实施并验证偶极导数时，IR强度应继续为`NOT_COMPUTED`，不能用振型大小冒充吸收强度。

`focused-check/`保存S01/S04官方摘要核验与短引文；`independent_metadata_records.json`保存其余书目和范围核验；`review.json`保存16项原文件完整性检查及独立AST结果。直接Crossref等API访问遇到环境代理403，其失败回执也保留在`metadata_receipts/`和`focused-check/`；随后使用可访问的官方网页记录，没有绕过访问限制。既往封存资料中的访问失败只描述当时访问，不能推断这些来源永久不可访问。

这不是系统文献综述，不能证明斯皮诺素THz研究文献不存在。所有资料仍仅作背景，不产生新的理论正常模式，不证明当前855份样品的成分，不确认化学归属，不改变既有96.0234%分类结果。
