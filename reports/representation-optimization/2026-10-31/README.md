# 第二轮光谱表示与特征空间适配证据

本目录保存真实上传光谱的七类匿名产地组回顾性实验，原513训练／171校准池／171预测用途不变。基础模型改动与少样本标签贡献分开评价；用户尚未提供真实地名，不将匿名标签一致性解释为独立地理溯源证明。

实际完成54条源管线×30开发任务＝1620次源拟合和166,860条开发预测；60个适配配置×3个已锁定源模型×30任务×20支持抽样＝108,000次开发配置评价。最终为3个513样品源模型、2400组适配评价、410,400条预测；全范围敏感性另有6个源模型、1026条预测。所有源与适配选择先锁定，再评价固定预测组。

## 结果摘要

开发选出的SG平滑＋SNV＋收缩LDA最终151／171＝88.30%，参考SNV-SVM为152／171＝88.89%。三个源模型的适配主选择均为不调整。PLS局部记忆家族对照为85.84%，高于原PLS的83.63%，但同结构零支持对照为85.96%；这不是少样本标签带来的额外改善。

全2578点SVM／PLS10的100%属于预先列出的源模型敏感性结果，既非校准增益，也不能证明高频段物理有效或跨批次泛化。PLS5虽99.42%，却错过唯一的ZY02样品，宏F1仅0.8561。全范围负α和缺少仪器SNR的问题保留。
