# 跨植物深度学习迁移：独立复核

本目录仅作原件／准备输入重建、已保存模型的原生预测重放、真实优化器输入作用域核对及指标复算。**新增审计拟合次数为0**。构造同种子的初始网络用于校验初始化，不训练审计网络；不根据评价结果设计新参数。技术通过不证明生物学独立性、物理单位兼容或新批次泛化，也不是外部机构认证。

## 复算后的主结果

同一855条历史观测、同一五折、同一共享96轮目标微调、种子42／43／44均保留。以下为三种子均值，不是三个独立样本队列。

| 方案 | Accuracy | Macro-F1 | Balanced Accuracy | seed42／43／44正确数 |
| --- | ---: | ---: | ---: | --- |
| A 酸枣仁从头训练 | 87.2125% | 0.761616 | 79.4762% | 756／725／756 |
| Aextra 仅酸枣仁额外120步预训练 | 87.3684% | 0.767110 | 80.3333% | 746／733／762 |
| B 人参／西洋参预训练 | 86.4327% | 0.753854 | 78.5238% | 750／729／738 |
| C 黄芪＋天麻＋人参多头预训练 | 85.6530% | 0.733309 | 75.8639% | 744／724／729 |
| 预定source-only保守策略 | 87.9532% | 0.770571 | 80.2109% | 763／729／764 |

B相对A平均下降0.7797个百分点，C下降1.5595个百分点；相对额外120步的Aextra，B下降0.9357、C下降1.7154个百分点。仅B的seed43相对A多正确4条，其余两个种子下降；C三个种子均下降。不能挑选有利种子声称外部数据有效。

保守策略在前两折选Aextra、后三折选A，未选B或C。其相对A平均增加0.7407个百分点来自酸枣仁源内额外训练选择，**不能归因于外部植物数据**。所有逐seed改对／改错和B／C相对Aextra的对照均在[evaluation_review.json](evaluation_review.json)中。

## 检查边界

- 小预算诊断仅outer0、seed42、2／4轮、4预训练步。C实际比较两份已冻结真值文件及受拒访问分支后的完整20模型学习状态；不改写原主任务真值。D只在拟合后改一条query；H只在两源内固定半区分别置乱酸枣仁标签，外部标签不变。小预算结果不得选择或修改主网格。
- 核心训练只使用每折当前酸枣仁source；外部头保持HQ／TM来源组及人参物种语义，弃源头、重置BN运行统计并使用同种子新鲜ZY头与优化器。每一步真实ID、X、y指纹均从正确源数组重建；这不等于重新训练梯度或OS文件权限沙箱。
- 128点是预定插值工程表示，850条外部记录不等于已外部认证的850株独立植物。老师吸收系数长度单位、人参共同原料和批次仍未认证。水果未知时间／频率物理坐标、叶片缺独立样品，未混进此光谱迁移。
- 855条酸枣仁已曝光，每类目前一个来源批次；本轮是内部开发。96.0234%的历史MC-UVE＋SVM仍保留，但其表示和架构不同；迁移因果对照是同表示的新A及Aextra，不能跨口径归因。
