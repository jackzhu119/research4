## 根协议已固定的坐标规则

本轮A／B／C统一使用`np.linspace(0.21, 1.49, 128)` THz，在每条原谱内部作线性插值；四个源均覆盖该区间，**不外推**。随后固定逐谱SNV（训练协议ddof=1），需要学习的StandardScaler则由模型入口仅拟合当前source。坐标选择来自物理轴覆盖，不读取类别差异或预测结果选频段。

黄芪／天麻原轴的前612点与酸枣仁轴逐元素完全相同；只用老师数据时可以原轴截取。但为包含65点的公开人参，本轮使用共同128坐标。插值不会把人参变成128次独立物理频率测量或新增样品。其他轴方案留在[坐标审查](common_axis_proposals.json)作证据，不参与事后挑结果。

SNV仅消除逐谱仿射尺度差异，**不能证明α单位、厚度、反演条件、仪器或基质一致**。旧黄芪／天麻覆盖层中`cross_plant_transfer_status=BLOCKED`字节和含义保持原样；当前用户授权尝试后，必须在新协议另标`EXPLORATORY_ENGINEERING_TRANSFER`，不能静默改成物理兼容PASS。

折射率从定义上无量纲，但其反演和实际物理有效性仍待核实；黄芪n仅303条、缺甘肃100条，天麻n405条。本轮α主实验没有补齐或删除n缺失样品；若以后比较n，需另定义匹配队列，不能混用不同来源数量声称提升。

## 实测质量与重复风险

实际共同128轴共检查923,901个跨植物观测对：精确相同向量0对，逐谱去均值余弦／Pearson形状相关≥0.99999为0对。没有因此删除或重标任何观测；未发现严格重复不能证明未知原料祖先、扫描或采样批次独立。

共同128轴仍保留天麻871个、人参210个负α单元格；酸枣仁／黄芪该区间无负α。它们是物理反演／质量待核字段，不能为了提高分数清除或重新选择窗口。最大相关对、全部逐源统计及原始和共同轴n质量均在`audit.json`，不对目标验证／外层query作学习。
