- 天麻现在具备**405**个既有样品、4个匿名组的完整四表示入口；黄芪具备**403**个既有样品、4个匿名组的完整四表示入口。可补做同样本集合上的α-only、α+n、α+time及四表示融合对照。
- 旧天麻time202只覆盖吉林/云南两组，新time405覆盖四组；旧黄芪n303仅三组，新n403覆盖四组。不能直接用前后不同类别/样本集合的准确率之差声称融合改善。应在当前完整403/405相同ID、相同拆分上同时重建基线和融合模型。
- 这些父样品的α及标签此前已经用于开发或验证；新时间表示第一次在本审查范围内可读，不会使其变成新的独立确认样品。所有表示与父实体必须同训练/校准/预测角色，转换和选参仍只能在当前训练内完成。
- 尚无新仪器、绝对物理量单位或真实跨批次独立性核验。此补充支持多表示工程实验准备，不构成化学归属、跨批次成功或准确率提升证据。
