# 6. E2：选择稳定性的来源分解

## E2a：已有掩码分析

先复用旧 V4 掩码及后续共同完整重复的外层掩码，协议分别报告。

严格区分：
1. 不同流程在相同训练集上的选集差异。
2. 同流程随训练子集变化的稳定性。
3. 固定训练集、只改变 MC seed 的稳定性。

对齐实际频率与局部/全局坐标，避免 α 在联合空间中的索引偏移造成虚假的低重合。

输出：
- 选点数 K 分布。
- exact-frequency Jaccard、intersection。
- 各频点入选概率。
- Nogueira Φ。
- 不同来源与参数条件下的描述性结果。

α 空间 p=612；完整 α+n 空间 p=1224；joint 的 α 投影仍为 p=612，但实际 K 可能变化。三者明确分开。

Nogueira 按原文 Definition 4 实现，保留负值，分母为零时报告未定义。不要设置“Φ>0.8 即合格”的事后门槛，不假设重叠训练集产生的掩码彼此独立。

Review 中约 0.811 的流程内 Jaccard 与约 0.011 的跨流程 Jaccard，只作为需要核对的报告值，不是程序应当硬性达到的目标。重算不一致时定位原因并保留差异。

若有效物理频率分辨率未确认，增加固定 4/8/16 连续网格点分组的敏感性分析：
起点统一从第一个频点开始，记录尾组大小；报告组占用与组级 Jaccard。
不把网格宽度称为仪器分辨率或化学峰宽，不挑选最有利尺度作为唯一结果。

## E2b：固定训练集的 MC 随机性

按冻结 manifest 的原始顺序，选择前三个共同完整重复的 fold 0 训练集，不按成绩挑选。

固定：
- 3 个训练集。
- 每个训练集 30 个 MC seed：
  2026111600 至 2026111629，完整清单写入 manifest。
- MC20、PLS components=2、K=62。
- 两种排名设置：
  A：α-only。
  B：真实 n 作为排名上下文，最终仅从 α 中选 62 点。
- 两设置采用相同的类别内样本抽样 ID，记录实际抽样以验证配对。

总计 180 次排名；沿用五类、每类 MC20 的实现时约 18,000 次 PLS1 拟合，以实际计数为准。

此次只运行排名与掩码，不训练 SVM/MLP。不能由掩码稳定性直接声称分类准确率对 MC seed 稳定。

同一 α 排名可派生 no-gap、fixed-gap=4，以及该上下文中已经由内层选定、此次保持固定的 gap 掩码，无需重复排名。

“联合空间总共选 K62”与“n 提供排名上下文、最终 α-only K62”是不同流程。若同一已验证排名可以派生二者，可额外保存，但必须分别命名。

不得自动把本模块扩成 MC100/500 全矩阵；已有 MC100/500 结果先按共同划分复用。

分别列出批次数、每批物理样品数、技术重复数和成本。
当前每来源单一已知批次不能可靠识别批次间方差；样本量敏感性分析使用的相关性和目标差异必须标为假设。

后续更新实验预先冻结 Source、候选模型与更新规则。
目标批次划分最大 Support 池及固定 Query，按物理实体隔离。
可设每类 1/3/5/10 个 Support 的机制诊断，各预算使用同一 Query。
若使用按类配额，明确其利用标签的采样条件；实际标注效率分析计入预筛选及满足配额所需的全部标签成本。

比较：
不更新、真标签完整 refit、冻结 Scaler 与数值 gamma 的 refit、
保持 C×N 的 refit、仅源损失控制、无标签统计更新、循环错误标签对照。
沿用已验收 B 轮的精确定义，记录每一项信息使用范围。

Query 不参与跨样本统计、选特征、超参、阈值、早停、fallback 或方法挑选。
使用 Query 无标签分布的方案必须另列 transductive 协议。
多次 Support 抽样不能增加独立 Query 样品数或独立批次数。

未提供真实新数据时，状态为：
BLOCKED_WAITING_NEW_BATCH_DATA

此时交付采样方案、metadata 模板、角色划分规则、预算、运行入口设计与验收条件，不用历史数据重新拆分冒充外部验证。

# 12. 验证、停止与交付

新增计算前冻结：
输入 hash、代码版本、split、所有 seed、候选范围、比较列表、
指标定义、任务队列、预算与失败处理规则。

执行顺序：
E0 → E1/E2/E3 → E4 所需缺口；
E5 与 E7 协议可并行整理；
E6 按开关执行。

做必要的样本隔离、预测配对、指标计算、坐标映射、复放和断点恢复验证。
外折结果不得影响候选、seed、重试或停止规则。
数值失败保留原因，不因成绩低而排除成功完成的实验。
仅有可识别基础设施原因的失败允许按同配置有限重试，全部计入预算。

不要新增 DFT、无关预训练、大型深度网络、主动学习矩阵或完整 MC100/500 搜索。
不要重新运行已完成的大队列。

至少交付：
