# 四轮优化：入选与最终模型

本目录保存真实执行产物的原样副本，逐文件原路径、SHA和大小见[manifest.json](manifest.json)。使用边界和结果见[四轮报告](../../docs/MULTIROUND_OPTIMIZATION_REPORT.md)。

- `neural-base/`：18个已锁定开发上下文和3个最终种子上下文的MLP权重、源预处理器及元数据。最终推理使用`final/`，开发模型只用于复核选择流程。
- `support-svm/final/`：保存原源完整管线`source_model.joblib`，以及预选诊断首个支持抽样的新SVM分类器。新分类器接收原源管线变换后的特征；复现`w001`还需按`0.9×原源decision scores＋0.1×新模型decision scores`混合再取argmax，不能直接把新SVC的predict当作完整诊断结果。该诊断没有提高最终准确率，不是正式替代模型。
- `anchored-ft/final/`：三个种子首个支持抽样的预选微调诊断权重。使用对应种子的`neural-base`最终源预处理器；正式方法保留原MLP，不采用这三份诊断副本。
- `meta-refinement/final/`：三个种子、100及500次源更新的FO-MAML与配对监督继续训练权重。100更新源方案是预先指定的正式回退，500更新为预选诊断。二者都不含目标支持校准；不能把源权重推理称为7样本校准结果。

输入仍为原频率坐标0.1—1.5内612点吸收系数，类别顺序ZY01—ZY07。MLP预处理为逐谱SNV和仅源拟合逐频点StandardScaler，不使用预测批次统计；此轮选中的MLP没有PCA。网络结构在`neural_base_search.py`，64–32双隐层ReLU＋7类头。PyTorch源权重需重建该结构并用对应预处理器；不得将编号或标签当作数值输入。

正式100更新源方案平均90.2534%／宏F1 0.878657；FO与同预算监督继续训练在本次每种子171个预测上分类完全相同，原始分数和权重不同。500更新诊断90.6433%不是事后替换的正式成绩。原SVM仍作为传统参照。全部仅单批次回顾性结果，尚未证明真实跨批次泛化。

其余非入选开发权重缓存未复制到GitHub；全候选指标、预测、训练清单和原SHA已在[证据目录](../../reports/multiround-optimization/2026-10-31/README.md)封存，可用冻结协议重新执行。源权重、每次目标支持编号及逐样品结果各有独立记录，适配副本不覆盖原源模型。
