# 第二轮实际冻结源模型

本目录保存三个最终源分类器，均仅使用固定训练组513份样品拟合；171份校准池和171份预测样品未参与其训练。它们从本轮实际执行产物原样复制，文件SHA、大小及训练样品数见[manifest.json](manifest.json)。

| 文件 | 预处理与分类器 | 身份 |
| --- | --- | --- |
| `s010_snv_svc.joblib` | SNV＋RBF-SVM，C＝10 | 原方案参考，最终152／171正确 |
| `s024_sg0_snv_shrinkage_lda.joblib` | SG平滑＋SNV＋等先验收缩LDA | 训练组内部开发选出的源候选，最终151／171正确 |
| `s014_snv_plsda.joblib` | SNV＋PLS-DA，10潜变量 | 预先指定的PLS家族诊断，最终143／171正确 |

输入必须是原坐标0.1—1.5范围对应的612点吸收系数，保留原频点顺序。模型对象自身包含预处理、训练缩放和相应表示；不要把全2578点、折射率、样品编号或标签混入数值输入，也不要在预测组重新拟合其步骤。可使用模型的`predict`或按固定类别顺序对`predict_scores`取argmax；分数不称为已校准概率。

SG配置为15点窗口、三阶多项式。类别始终是ZY01—ZY07匿名组，真实地名以后补充显示映射，不应为改变名称重新排序已拟合的类别分数。

这些是**源模型文件**，不包含已验证有效的校准器。三个基础模型的适配主选择均回退为不调整；不能把目录中的新文件称为校准成功模型。LDA在开发上胜出也不等于其固定预测准确率超过参考。

Python／依赖版本和代码hash在[Stage B执行清单](../../reports/representation-optimization/2026-10-31/latent-search/latent_run_manifest.json)中。完整训练用途、源选择、匹配零支持对照、负结果与复现命令见[第二轮报告](../../docs/REPRESENTATION_AND_LATENT_REPORT.md)。本轮仍是单批次回顾性匿名分类研究，不构成独立新批次或真实地名核验。
