# 校准探索的六类辅助源模型

本目录两个模型使用原训练组中除ZY02以外的510份样品拟合，属于单独的六类样本量辅助实验。类别为ZY01及ZY03—ZY07，不能将其93.53%等成绩解释为七类校准提升。

模型在最终100次支持抽样中保持冻结，原样复制自实际运行产物，文件SHA和指纹见`manifest.json`。输入为固定0.1—1.5候选区间的612点吸收系数，流水线自身包含SNV、缩放及相应筛选，不能在预测组重新拟合。

七类主模型继续使用[原冻结模型](../zaoren_threeway_20261031/README.md)。算法、支持编号、选择锁、依赖版本及全部正负结果见[探索报告](../../docs/CALIBRATION_OPTIMIZATION_REPORT.md)。
