## 历史实验的适用范围

2026-10-31，用户确认原855条ZY编号记录各为独立样品、每组只有一批，证据见[历史用户声明](data/annotations/zaoren_user_declaration_20261031.json)。该声明只覆盖原855条，不自动扩展到新增工作簿或黄芪，也不产生实际批次编号。

当时按[批准方案](docs/APPROVED_ZAOREN_EXPERIMENT_PLAN.md)完成13路径／65外折；历史报告中候选区MC20＋SVM准确率90.41%、宏F1为0.8092，原始正负结果保留于[执行报告](https://github.com/jackzhu119/research4/blob/research/algorithm-review-and-baselines-20261030/docs/ZAOREN_APPROVED_EXECUTION_REPORT.md)。这些是**现已知混合了枣仁和酸枣仁的7个匿名组内部验证结果**，不能继续称为纯酸枣仁的产地鉴别成绩，也不是本轮18表、1672谱上的实测结果。本轮没有重跑模型，Gaussian仍不属于此前批准实验。

后续开展同种类内产地识别、模型改进或新批次小样本校准，需要结合本轮种类标签重新检查实验分组和种类／产地／批次混杂。每组仅一个来源批次的样本级内部验证不能证明跨批次表现，独立新批次支持集与查询集仍待补充。
