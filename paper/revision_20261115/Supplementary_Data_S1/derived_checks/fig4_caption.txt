Figure 4. Support-label and preprocessing controls for the five-source Suanzaoren task. Points show archived internal query accuracies, with the dashed line marking the source-only model (80.00%). The full-refit endpoint with true support labels (83.89%; B1/B3) is compared with frozen scaler and kernel scale (83.78%; B2), unlabeled support statistics (80.11%; B3), cyclically incorrect support labels (73.33%; B3), and normalized total loss mass (83.78%; B4). Each context uses 190 source specimens, a 50-specimen support pool and 60 query specimens; K=10 per class supplies 50 additional labels where applicable. Three partition seeds and five outer folds reuse the same 300 master-TRAIN specimens (900 repeated query predictions). B1 and B3 full-refit values refer to the same archived endpoint and are not independent replications. The unlabeled-statistics condition does not use support labels in classifier fitting. All results are exploratory internal comparisons on previously exposed specimens; no new-batch evaluation is represented. No confidence interval is plotted.
