# 第二轮：光谱表示、基础模型与特征空间适配协议

2026-10-31，机器协议为[representation_calibration_protocol_20261031.json](../data/research/representation_calibration_protocol_20261031.json)。参数在真实运行前固定，本页为对应说明。保持原855份匿名样品及513训练／171校准池／171预测分组，七类均保留，不加入Gaussian。

基础模型与小样本收益分别评价。先比较54个源管线：原谱、SNV、SG平滑后SNV、SG一／二阶导数后SNV、线性去趋势后SNV，搭配RBF-SVM、PCA＋SVM、PLS-DA、收缩LDA及Ridge。SG窗口15、三阶多项式，导数用真实频率间隔；主范围固定0.1—1.5、612点。PLS-DA使用独热类别，不能将产地编号当连续数值。

每个管线在原训练组内部做30个307源／103支持池／103开发预测任务。源管线只拟合307份，所有方法共享分区；ZY02在源子集中仅1份，不继续做不可执行的内层CV。前24任务选择、后6任务检验已选管线，以原SNV-SVM C=10为参考，平均准确率须提高超过0.1个百分点且宏F1／平衡准确率下降不超过0.5个百分点，否则保留参考。

进入适配的源管线为去重后的参考、通过源开发检查的冠军、最佳PLS及最佳线性模型，最多4个。使用冻结的表示，再比较60个配置：不调整、源锚定Ridge增量头27个、源记忆／支持样品局部近邻27个、马氏距离收缩中心5个。PCA、尺度、源头及协方差都只用源样品；零支持对照保留相同辅助头或分类结构。

适配继续使用相同30个任务，每任务20次每类1份支持抽样。前24选择、后6开发检查，候选须同时优于原源分类器和自身零支持对照，并满足同样的宏F1／平衡准确率约束。不通过则不调整。不得以更换辅助分类器造成的收益冒充少样本标签收益。

所有源选择及适配选择锁定后，用513份训练完整拟合各入选源模型并冻结，校准池每类1份、共7份，抽样100次，在固定171份预测样品上比较。所有正确与错误预测均保存，按ID与原匿名标签连接评分。完整导出2578点的6个源模型对照另列敏感性分析，不参与主选择，也不使用校准标签；高频段信噪及负吸收问题未因准确率高而获验证。

这是同批次回顾性探索。重复任务不增加独立样品数，当前预测组已有历史研究曝光；源开发通过不保证本轮预测上涨。结果分别报告基础模型变化和相对自身基线／匹配零支持的小样本增益。
