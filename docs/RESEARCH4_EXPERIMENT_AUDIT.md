## 4. 泄漏审查与证据等级

在可检查实现与记录中未发现当前外层样品用于当前拟合／选参：源统计、MC系数、特征、gamma和类别权重均仅用当前源；每外折独立选择，不聚合跨外折内层成绩回填参数。原R0—R4内层全锁之后才统一外层放行，实际UTC和源码hash一致。SVC原投票保持；用OVR argmax代替原R0会少对1份，不能混用规则。

**历史855份及测试成绩已被研究者反复观察。** 因此即使代码分区隔离，也不能排除整个研究流程逐渐适应这批数据。七个类别各只有一个来源批次，产地与该来源批次无法分离。结论是“没有发现所审实现中的直接分区泄漏”，不是证明生物学独立或全新无偏泛化。

本项目局部证据等级：E0只有汇总；E1有真实预测、标签和划分；E2另有冻结锁、源身份及权重重放；E3另有未参与开发的独立批次。五阶段当前均E2、均非E3。此等级是项目审计约定，不是期刊认证。
