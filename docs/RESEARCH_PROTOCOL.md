# 中药光谱研究：数据条件与实验协议

本协议以 2026-10-30 仓库核验为基础。算法逐文件结论见 [算法审读](ALGORITHM_REVIEW.md)。推荐先完成黄芪产地鉴别，再依有无标准化学测定值选择成分定量路线。

后续公开金银花/山银花FTIR基准已完成，见 [外部实测报告](EXTERNAL_BENCHMARK_REPORT.md)。五折行级结果支持保留SVM与PLS-DA基线，CARS/MC-UVE的增益不一致；数据缺少批次与物理样品映射，尚未验证跨批次或少样本校准。

阶段二已新增重复变量筛选、回归偏差/斜率收缩及分类分数校准模块，并在新药材谱行和药片/小麦迁移设置实测，见 [阶段二报告](RESEARCH_STAGE2_REPORT.md)。重复筛选没有一致增益；回归校准在部分设置有用。真实药材产地跨批次校准仍待带域标签的数据，后文“本次工程产物”保留首次审读时的范围说明。

36 个表中有 32 个尺寸声明为 `A1:A1` 但实际有多列数据，另有甘肃折射率表确实为空。新读取器使用 `reset_dimensions()` 重新扫描；未改写原始工作簿。0.1–1.5 THz 在现有网格中对应 612 点，只是参考文献可供比较的候选区间，不能在观察测试表现后反复调整成“最优区间”。

目前每个黄芪文件名只给出一个产地线索。一个文件是否对应一个批次尚未确认；若每产地只有一个采集批次，产地与批次会混杂。模型可能识别的是测量条件、供应商或制样差异。

## 论文方法中值得沿用的内容

- `小麦的产地鉴别研究6.docx`：SG/MSC/中心化/SNV、UVE、PLS-DA/BPNN/LS-SVM，是中药产地研究可参考的基本流程；文稿说明 240 份样品、720 条谱，提示必须核对重复扫描的分组方式。
- `基于太赫兹光谱技术的小麦筋度鉴别I（中文）.docx`：比较折射率/吸收系数、CARS、SVM/BP/CNN/SSA-SVM，可据此确定基线和特征选择对照。不能假定文稿报告的 100% 会迁移到中药。
- 赵海燕等《中国农业科学》2011,44(7):1451–1456，DOI `10.3864/j.issn.0578-1752.2011.07.018`：摘要报告两年度分别为 87.5%、91.7%，用首年度模型预测次年度为 48.3%。这些是该小麦论文的既有结果，说明跨年度稳定性是可研究的问题，不是本仓库中药模型的表现。
- 近红外/中红外融合论文涉及不同传感器信息。现有中药的时域、频域、折射率、吸收系数主要来自同一测量链，不能因为存在四个工作表就把样本数乘四；融合也不能弥补某产地整块缺失折射率。

哪些稿件是老师正式发表的版本、哪份代码对应哪个实验，需要进一步确认；当前资料只足以建立参考关系，不能证明严格复现关系。

## 主线 A：黄芪产地鉴别

目标先限定为一种经鉴定药材、若干已知产地的闭集分类。评价批次、年份或仪器变化时，目标域仍应包含训练中已知的产地。识别从未见过的产地属于开放集/新类问题，应另设协议，不能与普通四分类混称。

1. 确认物种、真实产地、采购/采样批次、独立药材与压片编号、重复扫描关系。按物理样品分组；有批次时增加整批留出评价。批次采集尽量与产地交叉，控制粒径、厚度、含水率及聚乙烯比例。
2. 首轮比较原谱/SNV（以及预注册的 SG、MSC）与 SVM、PLS-DA、简单线性模型。MSC 的参考谱只能从训练分区建立。频段、PCA、变量筛选和调参全部进入训练内流程。
3. 加入修正后的 CARS/MC-UVE。重复选择时以独立样品/批次为重采样单元，记录频率点或连续区间的入选频率、变量数和重叠稳定性。分类筛选使用合理多分类目标，避免把产地编码当含量。
4. 再比较稳定频段选择、同预算 SSA 寻优或轻量 1D-CNN。每个新增模块分别消融；同一外部测试集、相同样品划分及调参预算。
5. 主指标为独立样品级 balanced accuracy、macro-F1、各产地召回率及混淆矩阵，给出按独立样品/批次重采样的不确定性。扫描级准确率只作辅助，不把重复扫描当作独立置信区间观测。

## 主线 B：指定成分含量预测

先明确分析物、单位、标准方法及重复测定误差。例如黄芪甲苷或某种黄酮只能作为候选，不能在没有配对 HPLC/UPLC 测定值时确定为可预测目标。THz 对低含量成分可能主要反映间接相关结构；应评估水分、粒径、厚度等混杂因素，并避免把相关性直接解释为该分子的特征峰。

需要每个独立样品与光谱一一对应的参考含量、检测日期/批次、检出限和测定重复。先做 PLS、SVR 基线；报告样品级 RMSEP、MAE、R²、偏差及浓度范围，并与参考方法的不确定性比较。产地整数不能充当含量标签，品牌不能充当物种或真伪标签。

没有这些化学参考值时，可以做数据整理、无监督探索和算法工程测试，不能给出有实证意义的成分定量性能。

## 泛化和小样本校准

优先研究同一种药材的跨批次、跨日或跨仪器迁移。小麦方法可迁移的是流程/算法；小麦分类头的标签与中药产地无对应关系，不应直接当作中药模型权重使用。跨药材还涉及目标语义与成分变化，应独立研究。

每个目标域严格分成有标签的校准 support 样品和最终 query 测试样品；同一物理样品的全部重复扫描只能在一边。源域训练、目标 support、目标 query 三者应按研究目标检查物理样品重叠。

- 分类的 K-shot 指每个已知产地 K 个独立样品，而非 K 条重复谱。可比较 K=0/1/3/5/10；这些是设计候选，不是足够样本量的承诺。
- 至少比较不校准、仅目标小样本、源+support 联合训练、冻结特征后仅校准分类头等方法，重复抽 support，报告样品级结果分布。调目标适配强度时，不访问最终 query 标签。
- 回归可比较少量样品的偏差/斜率校正；若是同一批标准物在两仪器的配对测量，再考虑 DS/PDS。没有配对标准不能默认采用需要配对的校准传递方法。
- 使用目标 query 的无标签分布做 CORAL 等适配时，应明确是 transductive 设定，并与完全不访问 query 的 inductive 结果分开。

研究贡献候选可表述为“面向批次变化的稳定频段建模与少样本校准”。是否足以构成新方法，需要补文献检索、实现和外部验证后判断。

## 本次工程产物与尚未完成的部分

`src/herb_spectra` 新增与原压缩包分离的 Python 基础实现：读表、原谱/SNV、SVC/SVR/PLS、嵌套分组 CV、样品级和扫描级指标、目标域 support/query 按独立样品划分。它尚不包含修正版 CARS、MC-UVE、SSA、1D-CNN、域适配或真正的校准模型，不能把基础设施测试视为这些方法已完成。

`data/metadata_template.csv` 每行对应一个吸收系数谱列；真实样品 ID、来源标签、批次和化学值留空，避免从文件名自动生成研究结论。先前未归档的枣仁大工作簿也未纳入本次 9 文件检查。

当前最关键的补充是：老师论文与程序的对应关系、独立样品/重复扫描映射、产地与批次记录，以及是否有化学参考测定值。缺少这些信息时，本次不会报告中药分类准确率或含量预测误差。
