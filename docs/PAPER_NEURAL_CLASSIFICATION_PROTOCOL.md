# 光谱少样本论文启发的分类试验协议

2026-10-31，真实运行前固定[机器协议](../data/research/paper_neural_classification_protocol_20261031.json)。依据用户要求，尝试《A task-oriented few-shot spectroscopy benchmark: Empirical evaluation of meta-learning approaches》，[原PDF](../references/research-literature/fewshot-benchmark-2026/1-s2.0-S0952197625036255-main.pdf)、[DOI](https://doi.org/10.1016/j.engappai.2025.113593)。本试验为分类适配，不是论文逐项复现。

原文做NIR／MIR连续属性回归，使用共享ResNet1D比较学习策略，支持量5／10／25是每任务总数；当前改为7类交叉熵及每类1份、共7份支持样品。精确网络与网格主要指向未上传的附录B，作者固定公开快照还缺少被导入的`models/cnn.py`，因此不声称还原原论文结构或发布参数。原文噪声／漂移图是人工扰动，不是已验证真实新仪器。

共同编码器为紧凑ResNet1D：16／32通道、残差卷积、GroupNorm、8段池化、32维表示。固定SNV输入、相同骨干；不使用预测批次的均值、方差或标签。与原骨干宽度、BatchNorm及回归输出不同，均明确登记为工程适配。

采用种子42／43／44全部报告。原训练组内部6个开发任务，每任务307源／103支持池／103开发预测；先在源上做40轮监督初始化，再在相同100组源任务编号上分别做监督继续训练、分类ProtoNet及一阶MAML。额外更新次数匹配，不声称FLOPs或耗时相同。

源元任务每次3类，各1份支持＋1份源查询，二者物理ID不重叠。只选至少2份源样品的类别：开发阶段ZY02源样品仅1份，不能进入元任务，但始终保留在七类监督初始化及目标评价中；最终513份源样品中ZY02有3份，七类都可进入元任务。类别词表跨分区相同，互斥的是物理样品及其标签记录，不是类别名称。

ProtoNet在局部3类原型上计算源查询损失；监督网络和FO-MAML保留7类头。FO-MAML以源支持损失形成快速权重，再用源查询梯度更新初始化，并明确采用一阶近似。源查询用于元训练，最终171份目标查询只评分。所有策略共有数据和编码器，但任务头及优化目标不同，不能称除学习规则外一切完全一致。

目标比较冻结骨干后微调分类头、全网微调、分类原型及FO-MAML后微调，共31个配置。微调学习率0.0001／0.001／0.01、1／5／10步；原型使用源中心与目标中心的4种固定混合。适配使用模型副本，源模型权重及统计保持不变。原型与同一元训练编码器的零支持源中心对照比较，FO-MAML与自身零支持分类头比较。

开发每任务5次支持抽样，前4任务选择、后2任务检验；指标在三个种子上平均，不挑最好种子。平均准确率增益需超过0.1个百分点，宏F1／平衡准确率下降不超过0.5个百分点，否则保持自身零支持方法。锁定后用原513份训练完成最终源训练，校准池100次每类1份抽样，171份预测始终固定。预先随机选20个ID展示，保留错误。

这是固定预算的早期可行性试验，同批次重抽任务不构成真实多批次泛化。所有收益先相对该神经方法自身零支持基线计算，再与现有SVM的绝对水平对照；不得把弱神经基线的相对提升说成超过已有最强模型。结构、训练预算、SNV与原文的不同也限制了对原论文方法的总体结论。
