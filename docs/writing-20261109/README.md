## 一页判断

1. **先纠正研究对象，再评价算法。** 枣仁与酸枣仁应按修订登记分开；陕西延安350份光谱只计一次。不同压缩包名称不构成不同样本。
2. **原有分类工作仍有可引用的价值，但必须按实际数据版本解释。** 物种修订后的固定预测集成绩与最新历史TRAIN机制诊断属于不同评估，不能合并成一个“最终准确率”。
3. **校准增益主要体现为阈值移动。** 本轮anchor与bias-only的逐样本比较支持该机制。正分数缩放的等价性有“斜率仍为正”的条件；已观察到的负斜率反例必须保留，详见机制结果页。
4. **跨物种迁移存在小幅平均改善，但尚不稳定。** 必须同时比较目标域额外训练和辅助标签置乱对照，报告全部随机组合。平均提高不等于已证明跨批次有效。
5. **BN解释了部分差异，尚不能作为唯一原因。** 仅使用源数据重估BN的探针与中性BN探针各有固定匹配对照；不能将不同种子子集直接拼接比较。
6. **光谱分类不能替代植物身份鉴定。** 尚无包装/供货/采集制样记录或独立鉴定证据可以确认陕西延安材料的真实物种。保留原登记标签并说明这一限制。
7. **理论计算是辅助证据。** 原始虚频、后续修正与导数验证应分清版本；IR未计算，不能据频率接近直接做药材实验峰的化学归属。
