# 写作取舍与图表清单

本页是写作建议，不是补做实验或新的统计结论。准确数字与出处以[数据页](DATA_AND_VALIDATION.md)、[历史实验页](EXPERIMENT_HISTORY.md)和[机制结果页](DEEP_MECHANISMS_RESULTS.md)为准。

## 建议主线

以“修订物种标签后的太赫兹种类鉴别与同种药材产地识别”为主体；将支持集校准、供体覆盖与跨物种预训练作为有严格对照的辅助算法研究。分子导数一致性与虚频诊断可作为辅助方法学/补充材料，不能替代实验化学鉴定。

不要把旧混种数据、修订后的固定预测集、999份历史TRAIN中的机制任务和不同量子程序版本混成一条性能提升曲线。每张表都应注明数据版本、任务、拟合范围、查询集和是否重复评估。

## 建议图形

- 数据血缘与验证设计图：原855、修订1672、固定三划分，以及本轮仅TRAIN内机制任务的边界。图中不能把重复RAR再画成一个独立队列。
- 校准曲线：固定查询集，横轴每类支持数K；分开画anchor、bias-only与完整重训。不存在的K3/K10完整重训点不要插值冒充结果。
- 迁移对照图：展示所有24个交叉随机组合的B−Aextra和B−Bshuffle差值，辅以均值；不只画最优种子，不把算法随机性画成生物学置信区间。
- BN匹配配对图：固定相同种子与样本，对比native/neutral/source-recal。将3种子探针与8×3主实验分开呈现。

当前提供结果表和来源；图形属于建议，未生成的图不能标作已经完成的实验。

## 可以支持的表述

- “基于修订登记的现有数据，对药材种类及同种药材来源组进行内部验证。”
- “在本实验设计中，anchor与bias-only产生相同预测，支持阈值移动机制；斜率反转的预定对照例外单独报告。”
- “跨物种预训练在部分设定中出现小幅平均改善，但对种子、微调方式及BN状态敏感。”
- “真实未见批次的迁移效力及材料的植物学身份仍需独立验证。”

具体数值应按对应表格的范围引用，不把三种模态或不同随机组合中的最佳值作为统一结果。

## 不能据当前证据写出的表述

- 旧96.0234%是修订后纯酸枣仁产地识别的准确率。
- 陕西延安样品已被光谱模型“鉴定为酸枣仁”，或按模型预测擅自改标签。
- CAL样本加入完整重训后的结果属于少样本分数校准。
- 多个种子重复评估的总行数就是新增独立样本数。
- 当前跨物种内部任务已经证明真实跨仪器、跨制样或跨批次校准有效。
- 所有负频均已消失、完整Hessian已被独立验证、结构是全正频最低点，或已完成IR峰的实验归属。

## 尚缺的关键验证

以下为**未完成的验证需求**，不是待后台自动造出的实验结果：

1. 陕西延安材料的可追溯记录与独立植物学/化学鉴定，先解决标签真值问题。
2. 同物种、同产地的独立新批次，必要时跨日期/制样/仪器；将批次与产地因素分开，建立预先锁定的support/query方案。
3. 小类补样与来源覆盖，特别是目前极小来源组；不能以增加模型或随机种子代替真实样本。
4. 如果要主张化学机制或实验峰归属，须另有标准品/可靠实测化学证据及相应谱学对照；现有理论邻近性不足。

## 开始落笔前的核对

- 摘要中的样本数、物种数、主要准确率及分母能回到一份明确的来源文件。
- 方法中的采样/厚度/仪器/批次只写已有记录，不补编。
- 结果分清“固定预测集历史重计”和“历史TRAIN上的探索机制”，在正文保留对照及负结果。
- 讨论列出无法完成的外部验证和身份鉴定，不将它们放进“已验证”结论。
- 参考本目录的发布状态核验，引用不可变提交或有哈希的原报告。
