## 2. 独立性、批次与固定角色

原855份ZY样品的独立性依据为2026-10-31的用户声明，每组一批。其余817份的独立性另依据2026-11-08“每列都是独立实物样品”的明确回复。全部样品以 `physical_sample_id=record_id`登记，但两次声明不等同于实验室审计，也没有提供额外批次编号。[D2]

主名单为 `data/research/species_revision_20261108/split_manifest.csv`，SHA-256 为 `0767e3165984a4e0e4ae782d69fdea6f410bfe36bce05ec72f8eadca982317d4`。原855份逐样品继承513训练／171校准／171预测的历史角色；新增817份按约60%／20%／20%分配，3份小组为1／1／1，5份组保留3／1／1。不根据谱值或模型成绩选择名单。[D3]

这些名单中的历史样品已曝光于此前开发；“固定预测池”不能称新外部盲测集。来源组及单一来源批次混杂，样品互斥不证明跨批次泛化。枣仁极小来源类每组仅3份，单条预测正确率只作诊断，不能主张稳定产地识别。[D1–D3]

## 3. 信号表示与质量核查

现有提取流程逐列配对吸收系数α和折射率n，核验工作簿哈希、记录编号、有限值、坐标单调性及谱列对应。主传统模型使用导出轴标注0.1–1.5 THz内的612个原始频点，不插值；n与α融合时按同轴配对。神经网络的α128／α512使用同一0.21–1.49 THz区间内的规则网格，显式插值且不外推。[D4, M1–M2]

导出标签与完整仪器物理校准并非一回事。旧时域数据经历过非均匀导出轴处理，时域单位未完整核实；不将该坐标直接写为经实验确认的物理时间，也不由此给出FFT化学峰归属。原始THz-TDS系统、样品厚度、含水率、环境、仪器参考谱与吸收系数反演条件，仍须依采集方记录描述，仓库缺少的参数不能猜填。[D4, M3]

## 5. 最新MC-UVE＋SVM的实际实现

V4的十个传统家族分别检查α/raw、α/SNV、n/raw、n/SNV、双SNV拼接、原n＋SNVα拼接、均衡分块筛选、缩放后模态加权、MC100，以及五次独立MC20排序聚合。主分析中的MC20／PLS潜变量2／每次80%来源样品，种子42；选择得分沿用仓库OVR-PLS回归系数均值／标准差稳定性实现，没有将其改名为新算法。[M1]

每个内折独立拟合预处理、StandardScaler及变量排名，再比较绝对特征数K＝31、62、123、184、245；SVM采用RBF核、`class_weight=balanced`，C＝0.1、1、10、100，γ＝scale、0.1×scale、10×scale。加权家族的模态权重同样只在内折选择。内折优先Macro-F1，其次Balanced Accuracy、Accuracy，再按预定复杂度规则打破平局。[M1]

每家族的主模型由内折同时确定K／C／γ；外折的所有固定K结果作为消融保留，不看外折成绩挑K替换主结果。每折最终在240份来源训练样品重新拟合完整流程，对60份查询预测。三种划分种子为20261031、20261108、42；模型种子42。[M1]

MC100和五次MC20均为100次系数抽样预算；分块MC20需每模态各20次，合计40次，不能称与单模态20次完全同成本。特征稳定性比较需控制K，避免把更多保留变量自然提高交集误认为更稳定。当前主候选是SNV＋MC-UVE20＋SVM的内层选参流程，而非唯一固定特征数或一套跨所有折通用的参数。[M1]

同source／query加入全α收缩LDA与MLP。LDA为 `solver=lsqr, shrinkage=auto`；MLP所有缩放和早停样品仅来自当前source，模型种子42。V3真实运行遭遇scikit-learn 1.8字符串标签早停错误；V4仅对MLP内部编码成整数再映射回原类别，历史失败成本与结果均保留，未修改原始标签。[M1]

## 6. 神经网络、跨植物迁移和校准

神经模型沿用已有科学编码器、损失及优化器。目标五来源头与黄芪／天麻各自来源头独立；辅助植物产地标签不映射为酸枣仁标签。A只用目标训练，Aextra增加目标训练成本，HQ-only／TM-only／HQ+TM使用辅助来源预训练，再拟合目标头。没有把不同种类的标签混成一个目标产地分类任务。[M2]

主要因素为α128／α512、190来源＋50支持＋60查询或240来源＋0支持＋60查询、辅助来源，以及训练预算。辅助预训练固定480步；240来源×144目标轮为576优化器更新，与190来源×192轮的576更新匹配；240×192为768更新。相同更新次数仍不保证完全相同样品曝光或FLOPs，论文须写明这一限制。[M2]

校准使用独立的少量support，固定比较零支持、相同分数结构的零标签／identity、传统和弱／保守修正，记录纠错与误伤。保持原预测不变是合法的保守结果，但不能把“没有变差”写为准确率提高。支持多次抽样不增加独立查询样品数；完整加入100份校准池重新拟合预处理／特征／模型，属于增加标签完整重训，不是K-shot冻结模型校准。[M2, D5]

## 7. 指标、统计及计算成本

统一保存Accuracy、Macro-F1、Balanced Accuracy、逐类Precision／Recall／F1／support和混淆矩阵。聚合时明确是各折、各重复或OOF池的指标；不把不同加权方式的F1混成一个数字。类别平衡时Accuracy和Balanced Accuracy可能相同，这不代表两项独立证据。[M1–M2]

比较新主模型与旧修正后融合模型时，逐样品对齐真值和所有外折角色，统计旧错改对、旧对改错及净变化。区间使用实物ID为聚类重采样单位，保留同一实物的重复预测，不把900条OOF记录视为900个独立观测。已有差异区间包含零，不能宣称统计确认提升。多模型长期探索还存在方法选择偏倚，当前结果应定位为内部开发。[M3]

计算成本区分实际科学阶段CPU／墙时、全队列控制与备份成本、失败成本和缓存复用；不把选择器局部耗时当端到端总训练耗时。队列完成数不是独立样本数，也不是不同算法数。工程测试、输入哈希与封存审计证明可追溯性，不等于外部临床或产地验证。[M3]

## 8. 可重现入口与安全使用方式

先从固定提交阅读原协议及`jobs.json`。其命令记录绝对路径、参数与输入哈希；新机器重现时只改路径并使用全新输出目录，不能覆盖原封存目录。原运行环境、版本清单和依赖锁见该任务的输入锁、授权／资源记录与已封存回执。NPZ属于可重建缓存，缺少本地缓存时需按已有工作簿和提取代码重建并校验哈希，不假装模型joblib孤立文件就包含全部变换信息。

已有本地环境可查看以下入口的参数，不应为论文汇总重复启动全矩阵：

```bash
python scripts/research4_matched_feature_validation_20261108_v4.py --help
python scripts/research4_representation_transfer_validation_20261108_v4.py --help
python scripts/prepare_species_revision_features.py --help
```

最终V4清单与代码在固定提交 `71a303e089c7c7b7b2557d62372aaceda44e2f91`；原1305项实验的尾部续跑及总报告在 `df3e12656e2177cfcf0a298e66bdedc5c524cb74`。不同分支有各自目录结构，论文复现说明应使用commit＋路径，不依赖会继续变化的分支名。[M1–M3]

## 9. 写作边界

可以写：在种类标签纠正后，纯酸枣仁五来源内部分类仍有有效信号；MC-UVE＋SVM为当前较强且可追溯的传统路线；融合、增加抽样、提高分辨率和迁移不保证普遍提高；受控配置下观察到有限正迁移，校准增益不稳定。

目前不能写：已证实真实跨批次或任意未知来源鉴定；识别准确率达到所有植物通用水平；斯皮诺素峰已经化学确认；DFT使分类提高；测得某成分含量、药效或质量；提出了全新MC-UVE、SVM或元学习算法。没有标准品THz、HPLC／LC-MS和独立新批次时，可以完成范围收敛的计算／方法论文草稿，但应在限制中明确，不能补造这些实验。
