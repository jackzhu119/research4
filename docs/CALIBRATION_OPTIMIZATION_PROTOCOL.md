# 小样本校准算法探索与反复验证协议

协议编号`zaoren-calibration-exploration-20261031-v1`，2026-10-31在本轮真实数据探索前记录。用户授权反复探索校准算法并逐样品核对正确率。本协议新增开发流程，不改写既有固定λ=1的负结果。

## 输入与标签

保持现有513训练／171校准池／171预测的固定拆分，不移动样品。独立核对当前7份原件、四表编号、拆分标签、NPZ标签与物理ID；只确认已提供匿名产地组的一致性，不从模型预测推断或修改标签。真实省市与采样凭证未提供，不宣称已核验真实生长地。

七类主实验保留ZY01—ZY07，统一每类1份校准。另设单独标注的六类样本量辅助实验，排除仅5份的ZY02，按原用途保留510训练／170校准池／170预测，比较每类1／3／5／10份。六类结果不能替代七类成绩，原文件及七类标签均不变。

## 先在训练组探索

固定0.1—1.5候选区间α，分别使用SVM和MC20＋SVM。源模型参数固定为既有SNV、C=10、balanced RBF、gamma=scale；开发任务中的预处理、标准化和筛选全部只拟合任务内源训练样品。ZY02在某个开发源子集中仅1份，不在该子集继续做不可执行的内层CV。

每个任务范围从原训练组生成30个开发任务，按类别划分约60%源、20%支持池、20%开发预测。七类任务307／103／103，六类306／102／102。ZY02的3份原训练样品依次覆盖6种角色排列并重复5轮；其他类别按固定种子改变分区。每任务20次嵌套支持抽样，所有方法共用支持编号及开发预测组。

比较固定116种配置：不调整、旧λ=1锚定校正、弱混合和强正则的锚定校正、仅调整偏置、仅纠正支持样品误分类的残差、局部核残差，以及源类别中心与支持中心的收缩融合。仅误分类残差在全部支持样品已经分对时严格保持原判别。PCA和距离尺度只在源样品拟合；任何方法都不拟合预测组的均值、尺度或标签。方法是既有思想的工程组合，不自动称新算法。

前24个任务选择方法，以配对准确率增益为主；要求平均提升超过0.1个百分点，且宏F1、平衡准确率各下降不超过0.5个百分点。准确率相差0.1个百分点内优先更简单、更弱的修正。最后6个任务执行同样的开发门禁；不通过则保留原模型。该门禁仍属于训练组开发，不能称独立外测。

每个方法家族另保留开发选出的配置作诊断，不能等看过最终预测准确率后再更换主方法。每个候选还须相对自身零支持匹配对照通过同样的增益和宏F1／平衡准确率门禁。原型融合的零支持对照保留相同融合结构及源类别中心，区分收益来自源特征融合还是少样本标签；仅源融合获益不能当成少样本校准改善。

## 锁定后再评价

先保存并冻结所有配置、支持规则及hash，再在原校准池做100次固定种子的嵌套抽样。七类固定171份预测，六类固定170份预测，各自始终不变。分别报告源模型、旧校正、开发选出的主方法、家族诊断和零支持匹配对照。

模型只能接收数值光谱。每次先生成预测，再按定位ID与真值表连接，保存是否正确、改对／改错、准确率、宏F1、平衡准确率、逐类召回及混淆矩阵。预先按固定种子抽取20个展示样品，连同错误一起展示，不只挑正确例子。

开发和评价均保留全部正负结果，支持中断后按hash检查继续运行。不得根据最终预测标签挑强度、种子、样品、范围或重新定义任务。
