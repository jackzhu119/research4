# PySCF持续计算：质量记录与执行进度分开

当前用户明确要求：取消因科学收敛阈值而频繁终止的行为，在后台继续计算。
这项新指令覆盖此前本轮协议中的科学门禁、依赖阻断和禁止有限重试规则。
旧计算结果、native false、失败成本、原阈值和历史协议全部保留原样，不追改成成功。

新程序使用独立v3源文件、配置、工作目录和账本。光谱数据、物种/产地注释和
分类模型不变；量子计算结果继续单独报告，不改变任何旧分类分数。

## 现在怎样持续执行

普通电子SCF采用1e-10 Eh能量容差与1e-7轨道梯度目标。这些是正常求解器
收敛参数，不再加上此前会中止队列的1e-12主循环/额外循环双重认证。
旧严格标准仅作为结果中的诊断字段。普通SCF未收敛时可采用有限Newton
恢复；仍未达到求解目标但密度、能量和梯度均有限时保留native false及
质量警告，继续处理后续几何、位移点和其他任务。

每个点有自己的日志、实际求解尝试和检查点。异常或非有限输出不会当作
有效数据；程序会记录该点、有限恢复并继续独立点。单个失败不再通过
依赖状态使整套Hessian和后续独立分子任务全部跳过。前置任务虽有质量
警告，只要真实所需坐标/数组存在且来源可核对，后续任务仍执行。

原儿茶酸先从上轮最后合格的电子计算点继续优化。几何优化达到常规停止
条件或用完该阶段迭代后，都保存最新有限几何、核梯度、优化器原始状态
和质量诊断，继续计算指定几何处的完整中央差分Hessian。核驻点状态不
再作为是否计算Hessian的执行开关。两个步长相互独立；可进一步处理
Calycosin、网格或步长对照，直到真实排定工作完成或总预算耗尽。

核梯度继续使用grid_response=True，方法为PBE/def2-SVP、direct完整AO/MO、
每次重建native VEFF、明确无D3。默认grid3；另外的网格/步长作为单独
明确命名的计算，不混成同一矩阵。最终密度仅中心点需要回传；大量位移
点的中间密度/检查点可放local-only并保留哈希，逐点最终梯度正常保存。

## 结果怎样解释

完成数值计算和通过科学验证是两个字段。每个输出保留SCF原生收敛标志、
核梯度、原始Hessian反对称性、步长差及缺失/异常点。全部有限位移梯度
齐全时可以组装完整矩阵并给出全部有符号频率；有缺点时保留PARTIAL，
不能将补零或删除失败点后的结果称为完整矩阵。

在未严格核驻点处得到的频率明确标为该几何处的诊断曲率，不称为稳定
最低点振动谱。电子未收敛、核驻点未通过、步长/矩阵一致性未验证时，
minimum_verified不得设为true；即便全部频率为正也不自动升级结论。
虚频按符号保留，IR强度仍NOT_COMPUTED，不作药材固态THz峰归属。

保留总CPU、内存/进程清理、显式STOP、源/输入一致性以及未知进程身份

全部完成时记录完成，不用空循环消耗CPU。
