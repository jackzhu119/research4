# 已批准的酸枣仁实验方案：识别、候选改进与小样本校准

协议日期：2026-10-31。数据版本：`2026-10-31-zaoren-numbered-v1`。本方案依据用户对既有规划的批准及“每个编号均是独立样品”的明确确认执行；这是本地实验协议，**不是外部预注册**。机器可读规则见[实验计划JSON](../data/research/approved_zaoren_experiment_plan_20261031.json)，实际执行结果另行保存，不把本协议写成已经取得的性能。

## 1. 数据依据与结论范围

只使用[有效清单](../data/active_workbooks.json)中的7份酸枣仁编号版：ZY01为350份、ZY02为5份、ZY03—ZY07各100份，共855条记录。用户已说明每个文件对应一个产地，且每个编号对应独立样品；[声明证据](../data/annotations/zaoren_user_declaration_20261031.json)及当前元数据据此将酸枣仁`physical_sample_id`显式映射为`record_id`，依据字段为`user_declared_independent_20261031`，`origin_group_verified=true`。这项映射来自用户确认，不是从文件名自动推断。

当前分类目标为匿名组`ZY01`—`ZY07`。真实地名`origin`、批次、物种确认等未提供字段继续留空；黄芪注释不随之改变。当前正式结果须称为**“用户声明独立样品上的匿名产地组内部验证”**。不得称为已经完成真实地名核验、留批次／年份／仪器验证，或已经验证中药真伪及成分含量。

按当前数量，类别最大比例为70∶1，仅始终预测ZY01的准确率即可达到40.94%；必须报告宏平均F1、平衡准确率和逐类召回。ZY02全部5份保留，不删类、不复制少数类，不以SMOTE或重复扫描增加独立样本数。其外层测试每折仅1份，少数类召回的不确定性必须单独说明。

Gaussian及分子计算不纳入本轮。SSA、BP、1D／2D-CNN和元学习不进入首批主矩阵；老师原程序的既有兼容检查不重复算成本轮科学实验，Python CARS-style与MC-UVE明确标为独立适配实现。

## 2. 固定的数据处理与验证规则

1. 从有效清单核对文件hash、四表编号、坐标单调性、n／α一一配对、缺失／非有限值、精确及近重复和原厚度标注。质量失败先记录并停止受影响路径，不根据测试表现决定删样品或频点。
2. 首批主矩阵固定坐标区间`0.1 ≤ f ≤ 1.5`，按原表`Thz`坐标取点。这是工程参考候选区间，**不宣称已由仪器验证有效或达到最优**；单位和仪器信噪记录仍待补充。另执行全导出范围α的SVM／PLS-DA敏感性对照，不依据外层测试分数改变主区间。
3. 对通过质量门禁的全部855份样品，先按已提供物理ID归组；若后续补充记录发现重复，修正分组后重新生成分区，不能保留已知重叠。重复谱只在同组内按预设规则平均，不能跨训练与测试。
4. 外层5折、内层2折，类别分层并保持物理样品互斥；CARS内部CV为2折。分区seed固定`20261031`，模型／选择器seed固定`42`。在每个外折开始前核对全部方法所需的最小类数；失败记录为不可评估，不静默换折数。
5. 这套5／2／2设置针对ZY02只有5份的现实约束：外层训练保留4份，内层训练通常保留2份，避免原先3／3／3嵌套方案使CARS内部3折不可执行。它不消除少数类样本量不足的问题。
6. 原谱／SNV在内层选择；n＋α拼接时分别对两个模态做逐样品SNV，再拼接，不能对混合单位的整条拼接向量做一次SNV。StandardScaler、选择器和分类器均只在当前训练分区拟合。
7. 内层调参以`f1_macro`为主，`balanced_accuracy`为辅助指标。SVM用RBF核、`class_weight=balanced`、`gamma=scale`，C候选`0.1/1/10/100`；PLS-DA使用one-hot多分类目标和argmax，潜变量候选`1/2/3/5/8`并按训练维度裁剪。无序产地编号不得当连续含量。
8. 所有方法共享相同外／内层样品分区。外层测试标签只用于评价，不用于调参、选区间、挑种子、挑方法或校准强度；不能只报告有利折、类别或模型。

## 3. 执行顺序和最小对照矩阵

| 批次 | 输入与方法 | 目的 |
| --- | --- | --- |
| 质量与预检 | 当前7表、声明注释、n／α配对、5／2／2分区可行性 | 先确认真实输入与分区，不训练时也保留阻塞原因 |
| A：识别基线 | 候选区间α：多数类Dummy、全谱SVM、全谱PLS-DA、MC20＋SVM、CARS12＋SVM | 建立可核查的常规识别水平 |
| 模态消融 | 同一分区中n及n＋α各运行全谱SVM／PLS-DA；α对应结果直接复用 | 区分折射率与融合的影响，保持样品组成一致 |
| 区间敏感性 | 全导出范围α：全谱SVM、全谱PLS-DA | 检查候选区间依赖；不是根据结果重挑主区间 |
| B：候选改进 | 候选区间α：MC100＋SVM、重复MC（10×10）＋SVM | 将普通筛选预算和重复聚合分开比较 |

n与α来自同一测量链；这里的模态消融是配对信息表示对照，不把两表算作两组独立样品或两台独立传感器。所有表示使用相同物理样品与分区。

MC20／MC100／重复MC均保留`ceil(10%×输入点数)`，不把重复聚合的大变量数当作优势；记录选择器实际拟合数、最终点数、入选频率、Jaccard及耗时。CARS固定12轮、内部2折，子集大小按既有CARS-style规则确定，其选择路径和内部误差不是独立性能。重复MC采用10次外重采样×每次10次MC；其工作量含额外聚合／破同频处理，不谎称与MC100每一步计算完全相等。

在完整配对数据及全部范围通过门禁时，以上共13条“表示／方法”路径、65个外折场景；它们共享样品和分区，不是65个独立研究。全导出范围若未通过质量检查，明确记录该敏感性路径阻塞，不能为获得结果而临时删点、插补或回头调整确认标准。

稳定筛选、融合和其他复杂组合都只是候选。已有外部药材结果没有显示重复筛选的一致优势，本轮不预定它是最终创新；B不优于A也保留普通基线及完整负结果。

## 4. 阶段C：分类校准实现与真实实验启动条件

实现并核对五种已知类别适配对照：源模型不适配、仅目标support简单分类器、源＋support完整Pipeline重训、冻结源表示后重训分类头、`AnchorScoreCalibrator`分数锚定校准。完整重训与仅重训头分开命名；类别分数列顺序固定，分数不自动当概率。实现测试使用合成或有明确域标签的验证数据，不能改名成真实酸枣仁外部成绩。

**真实跨批次校准尚未启动：当前批次字段为空。** 七个类别文件不能充当七个多类别域／元任务，也不能用随机拆出的记录伪造新批次。现有5份ZY02不满足源、多个K的support及独立query的充分隔离，不能据此承诺统一5-shot／10-shot校准。

执行期间用户进一步确认“每个产地目前只有一批”。这是新增的数据来源事实，不改变已冻结A/B参数；它进一步说明当前内部识别分数不能区分产地效应与这一批来源样品的效应，真实阶段C仍需新的独立批次。

后续按来源批次、制样批次、测量日期及仪器分别记录，源训练、开发验证、最终确认采集轮尽量覆盖全部已知产地，并随机交错制样及测量。优先补充ZY02；每产地每目标采集轮约30份独立样品可作为组织目标，例如10份最大support池＋20份固定query，**这不是统计效能或准确率保证**。

条件满足后比较每类K＝0／1／3／5／10。先固定query，再从互斥support池做20次嵌套抽样，全部方法共用同一批query和support。K＝0表示不使用目标标签；K>0按独立物理样品计数，未抽中的support不回填query。目标池不足则该K不可执行，不能缩小测试量来凑K。适配规则、正则与强度仅在源／开发任务选择，最终query仅评分；如使用其无标签分布，另行标为传导式协议，不能与当前归纳式协议混称。
