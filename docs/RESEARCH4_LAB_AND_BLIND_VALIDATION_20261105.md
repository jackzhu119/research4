## 2. Spinosin标准品THz测量：建立参考证据

目标为可靠身份的斯皮诺素标准品。已有结构证据核实Spinosin为C28H32O15、75原子、CID155692／CHEBI:81360，但SDF不是实物纯度或固态结构证明。实验室负责采购／取得标准品并保存供应商、批号、CoA、纯度与校正依据、固相／水合或溶剂化状态、储存和有效期；当前全部LAB_REQUIRED，未代为采购。

测量流程交实验室确认后冻结：

1. 核验标准品身份和CoA；记录solid form未知项，保留原始证明。另测实际使用的空白基质、空白压片和参考，不把基质吸收写成Spinosin。
2. 先采用与药材尽可能可比、经仪器负责人认可的THz-TDS SOP。粉碎／干燥／基质及比例／压力／厚度／质量／参考／吹扫／温湿度／时间窗等具体数值当前TO_VALIDATE，本文不臆造。
3. 保存原始时域、参考时域、频率轴、物理量及单位、吸收系数计算代码和有效频段／SNR规则。不能只保留绘图均值；时间单位未知时不能声称已完成可靠THz变换。
4. 预先规定压片与扫描技术重复数量及汇总方法，记录其父ID。可规划3次独立制样与每片3次扫描作技术重复演练，**这是实验操作规划，仍是一批标准品，不是9份独立生物样品，也不是功效证明**。实验室可在冻结前按实际仪器条件调整。
5. 测量顺序随机／交错放置标准品、空白和药材QC，监控时间漂移；排除仅使用预注册技术QC规则，失败也归档，不能按分类表现删记录。

标准品实测峰可与真正合格的理论模式作探索对照，但不同晶型、水分、基质、氢键和晶格作用可改变低频谱。孤立分子模式、标准品固态谱与复杂药材谱属于三层证据。频率接近、注意力重叠或单一标准品峰均不能独立确认药材中某峰的化学归属。
