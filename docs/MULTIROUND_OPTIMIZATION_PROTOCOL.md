# 酸枣仁四轮后续优化：先行方案

2026-10-31，按用户“多进行几轮、记录每次结果”的要求启动。当前仅使用编号版855份真实光谱及匿名产地组ZY01—ZY07；沿用513份训练、171份校准池、171份固定预测。每个编号独立、每产地只有一批的依据仍是用户声明，真实地名待补。详细规则先记录在[总计划JSON](../data/research/multiround_optimization_plan_20261031.json)，各轮具体格点另有运行前冻结协议。

这次将四条不同路径分别记账，不要求每轮都提高分数：

| 本次轮次 | 修改内容 | 需要区分的收益 |
| --- | --- | --- |
| 1 | BP/MLP：源拟合逐频点标准化、PCA、网络宽度和训练预算 | 基础识别模型改善，不计作校准收益 |
| 2 | SVM：固定源预处理与超参数，在模型副本上加入加权支持样品重新拟合并融合分数 | 新增支持标签贡献；与同结构零支持重新拟合对照比较 |
| 3 | MLP：微调时加入源样品回放和参数锚定 | 与原源模型、同样继续源训练但不给目标标签的对照同时比较 |
| 4 | 较强MLP起点上的一阶MAML，改变源元训练预算与步长 | 源继续训练、元学习本身、目标标签校准三者分开 |

上轮已保存的神经模型在源训练样品上本身识别能力偏低，值得检验输入尺度和训练预算。该观察不能独立证明池化、SNV或某个具体实现是原因，因此本轮通过受控格点做比较，不先写成功结论。老师提供的BPNN／PCA／SVM思路可以作为基础模块；这里的PyTorch／sklearn实现及元学习扩展均明确记录来源关系，不能当作原MATLAB文件原样复现。

神经轮使用原训练组内部6个开发任务，前4个选择、后2个检验，种子42／43／44全部报告。SVM轮复用30个已有源开发模型，前24个选择、后6个检验。源元任务的支持和查询必须是不同物理样品；开发阶段ZY02源样品只有1份，不能拆成两份进入元任务，但保留在七类监督损失和全部目标评价中。

每类1份、共7份目标支持样品。七类3／5-shot当前不可行，因为ZY02校准池只有1份。所有预处理只拟合源样品；源对象保存并核验指纹，目标适配只操作副本。适配要同时比原源模型及匹配的无目标标签控制更好，平均准确率提高超过0.1个百分点，宏F1和平衡准确率下降均不超过0.5个百分点；不满足则按事先规则回退。

**四轮的开发选择锁全部写好并记录hash后，才统一评价原171份预测样品。** 后续轮次只依赖前轮的开发选择，不读取其最终分数来选模型。最终各轮100次支持抽样，固定预测样品不变；保留所有负结果、回退和预选诊断。全部仍是同批次回顾性探索；重复抽样不是独立新批次，也不是新的独立确认集。

每次候选、参数、开发指标、选择理由、最终逐样品预测、正确／错误标记、运行时间及代码hash均需保存，最后提供统一轮次台账与Excel。已有历史报告、模型和数据不覆盖。当前主线仍不加入Gaussian。
