## 如何避免旧结果回流

1. 论文只读取paper/current的清单文件，校验会拒绝额外混入的文件；禁止递归汇总所有reports或从Git旧提交恢复被撤回的分类成绩。
2. 删除规则以来源协议和目录为准，不能按日期、855、legacy或某个准确率数字批量删除。原始855谱和修正后1305矩阵继续保留。
3. 共享源码、修正实验的封印端点、当前18份原谱及量子对象在分支删除提交前后逐项比对；旧混合工作簿、旧论文包证书随污染包撤回，由新白名单校验替代。
4. 分支Git元数据可运行refresh_repository_inventory.py更新；人工状态与论文使用许可不能由Git提交时间自动推断。
