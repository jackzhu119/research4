## 科学规则

原儿茶酸为中性单重态C7H6O4，17原子、80电子。采用PBE/def2-SVP、grid3、
完整AO/MO及direct积分；不加色散，不称为D3。每个SCF循环完整重建native
VEFF，避免沿用增量势能误差；电子能差阈值保持1e-12 Eh、轨道残差1e-9，
保留实际原生收敛标志和fresh完整Fock复核。核梯度采用grid_response=True。
最多40个几何优化步骤；优化后fresh核梯度RMS<=1e-5且最大分量<=3e-5
Eh/Bohr才释放两个Hessian。每个核位移的正负两侧都从同一个认证零点密度
独立初始化，不串接相邻位移的终态密度。

所有位移只尝试有限次数。已合格点仅在输入/源代码/结果哈希一致时复用，
失败点保留；中断恢复不能让失败成本归零或重复领取预算。缺点或失败只输出
PARTIAL，不用不完整矩阵生成“完整45模式”。

分析保存原始反对称误差、质量加权矩阵、平移/转动投影及45个有符号频率。
预设门禁为两套原始Hessian相对反对称性分别<=1e-3、投影质量加权矩阵相对
Frobenius差<=1e-3。频率差门限为max(5 cm^-1, 最高频率的1%)，用于步长检查。
稳定极小值还要求全部振动特征值超过两步长矩阵差谱范数给出的经验不确定性裕量，并满足
电子、核驻点、完整性门禁；未达到则明确NOT_VERIFIED。所有负结果保留。
该裕量不是精确物理Hessian的严格误差上界。

IR强度持续NOT_COMPUTED。本轮孤立分子计算不建立固态药材THz峰归属，
不替代标准品、HPLC/LC-MS或独立批次实验，也不改变任何分类分数。

## 后台运行与保存

入口为 `scripts/run_pyscf_autonomous_90000_20261108.py`，配置、授权、状态、
CPU账本与日志统一保存在 `reports/pyscf-autonomous-90000-20261108/`。
独立session、stdin关闭并写文件日志；结束聊天不发送停止信号。使用独占锁与
PID/出生标识/boot核对防止重复运行，未知未闭合进程会阻止重复启动。
任务终结及运行中检查点会按配置将小产物回传本研究分支；不合并main，
不覆盖历史结果，不执行force push。大检查点保留本地并记录SHA-256。

后台运行依赖当前云实例仍在运行。云实例暂停、关机或销毁会中断计算；
独立session不提供基础设施持续在线保证。状态和逐点保存用于查验与安全恢复，
不能把“已启动”或“队列结束”写成科学计算已通过。

停止入口是在运行目录创建 `STOP` 文件，或向已核实身份的监督进程发送TERM；
监督进程会结束自己的计算子树并保存真实状态。

查看当前状态（包含真实进程存活核对）：

```bash
cd /workspace/research4
.venv-pyscf-90000/bin/python scripts/run_pyscf_autonomous_90000_20261108.py \
  --config reports/pyscf-autonomous-90000-20261108/config.json --status
```

首次启动使用同一入口加 `--detach`，并绑定已经记录的配置SHA-256。
存在账本时必须显式 `--resume`；它只继续尚未开始的步骤，已闭合失败不重试，
未知RUNNING阶段拒绝启动。跨云实例的中断恢复需要先审计真实历史成本与
尚未闭合点，不承诺自动恢复。安装版本锁在
`requirements/pyscf-autonomous-90000-20261108.txt`。
