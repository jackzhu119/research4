# 与现有 Excel 相近的太赫兹数据来源

核验日期：2026-10-30。检索以中国高校、科研机构和国家科学数据平台为先，并补充国外机构仓储。目标是数值光谱、样品标签及可追溯来源，而非只有论文中的曲线图片。

## 当前结论

**优先获取人参／西洋参光学常数、小麦粉苯甲酸定量、首都师范大学糖类原始信号三组数据。** 前两者分别适合分类与含量回归，第三者适合核对时域到频域的处理流程。剑桥大学的原始 THz-TDS 教程数据和 Python 程序也很有参考价值。

本轮尚未核验到覆盖中国或世界广泛产区、带真实生长产地标签的公开酸枣仁 THz 数据集。这是本轮检索结果，不能据此断言此类数据不存在。公开的其他物质 THz 数据可验证算法或处理流程，不能替代酸枣仁产地训练数据。

**来源检索阶段新增数据文件下载数、数值数组解析数和模型运行数均为 0。** 其核验范围是主来源页面、仓储说明、文件清单或 ZIP 目录预览。随后用户上传了人参 `Dataset.rar`，现已实际解压并解析18个CSV，生成[中文标注版与检查记录](../data/external/ginseng_hvbp5mdtxx_v2/README.md)；该包有20个亚洲人参、22个西洋参标签，没有产地标签。新增模型运行数仍为0，其他候选的访问状态保持下文所述。

## 与用户 Excel 的对应标准

现有工作簿有“时域、频域、折射率、吸收系数”四类表。候选来源不必是 Excel；CSV、TXT、MAT、HDF5 都可读取。判断重点如下：

| 数据内容 | 能支持的工作 | 仍需核对 |
| --- | --- | --- |
| 样品与参考的时域波形 | FFT、相位处理、光学常数反演 | 时间单位、参考类型、厚度、窗口和仪器 |
| 频率与折射率 n、吸收系数 α | 与现有 n／α 表比较，特征选择、分类或回归 | 频率及 α 单位、有效频段、反演条件 |
| 只有吸光度或太赫兹图像 | 可能支持谱分类 | 吸光度不能直接当作具有长度倒数单位的 α |
| 可信样品与标签表 | 训练及独立验证 | 物种、产地、浓度是不同标签；重复扫描不等于独立样品 |

近红外、拉曼、遥感反射率不列入这里的主要候选。FTIR 测得的远红外／THz 频段光谱单独标注，不能当作 THz-TDS 原始波形。

## 中国来源优先清单

### 1. 人参／西洋参：最接近 Excel 的 n／α 数据

来源为新竹的 **National Tsing Hua University（清华大学）**研究者发布的 [Mendeley Data V2](https://data.mendeley.com/datasets/hvbp5mdtxx/2)，DOI：`10.17632/hvbp5mdtxx.2`，2025-05-08 发布。机构位置应与北京清华大学区分。

仓储说明为 42 片压片、6 组；`Dataset.rar` 标示 23.6 KB，说明解压后有 18 个 CSV：6 个 `data_nj.csv`、6 个 `data_aj.csv`、6 个 `label_j.csv`。谱文件第一列为频率 THz，后 7 列为压片数据；n 为无量纲折射率，α 为 cm⁻¹。标签 `1` 为亚洲人参、`0` 为西洋参，**不是产地标签**。[官方版本比较页](https://data.mendeley.com/datasets/compare/hvbp5mdtxx)也保留了版本说明。

- **核验范围：**最初核验仓储说明；后续实际读取用户上传RAR，确认18个CSV、每个谱文件65行数值及7条谱、共同频率0.2–1.6 THz、20个1和22个0。物种编码与n／α单位依发布者说明解释；原包没有README或样品列名称。见[标签位置、配对规则与原件哈希](../data/external/ginseng_hvbp5mdtxx_v2/README.md)。原始sample/reference时域波形未提供。
- **用途：**老师的 PCA、SVM、CARS／UVE 等分类流程，n 与 α 单独及融合的对照。
- **样本限制：**42 片不自动等于 42 个独立植株或批次。V1 的频率网格不能强制套用 V2，应读取新文件自带频率。

同机构另有 [2026 年 Optical Constants of Ginseng Tablets](https://data.mendeley.com/datasets/k4pjjjmgnr/1)，DOI：`10.17632/k4pjjjmgnr.1`。说明为 4 套特征方案，每套 24 个 CSV，包含 6 折训练／测试数据与标签。96 个文件不是 96 个独立样品；与 2025 数据**存在重叠可能，尚未证实**，需样本 ID 或数值比较后才能判断。该来源同样是物种分类，不是产地库。

### 2. 华东交通大学：小麦粉中苯甲酸含量与 BP／GRNN 代码

[Dryad 数据集](https://datadryad.org/dataset/doi:10.5061/dryad.945c410)，DOI：`10.5061/dryad.945c410`。研究机构及方法见[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6689620/)。官方逐项文件说明明确列出：

| 文件 | 仓储说明 | 标示大小 |
| --- | --- | ---: |
| `data.mat` | THz 吸收系数和苯甲酸含量 | 41.29 KB |
| `X.mat` | 吸收系数的一阶导数 | 39.73 KB |
| `Y.mat` | 苯甲酸含量 | 1.38 KB |
| `fz.mat` | 频率 | 437 B |
| `BP.m`、`DemoBPNN.m`、`DemoGRNN.m`、`rms.m` | BP／GRNN 及误差计算代码 | 合计约 4.6 KB |

- **核验范围：**官方数值文件清单及变量用途；一次网页文件请求返回 403，未取得文件。不能把请求失败理解为数据不存在。Dryad 通用数据政策为 CC0；代码内部声明仍需取得后查看。
- **用途：**最适合先做 THz 定量回归复现，对比 PLSR、SVR、BP／GRNN、特征筛选。标签是添加剂含量，不是中药天然成分或产地。
- **待核对：**实际矩阵维度、独立样品数、频轴单位／范围、含量单位，以及代码对 MATLAB 工具箱的依赖。文件列出不代表已经通过 Octave／Python 实测。

### 3. 首都师范大学：糖类固态／溶液的 THz-TDS 原始信号

[Zenodo 原始数据](https://zenodo.org/records/6351093)，DOI：`10.5281/zenodo.6351093`；[论文及机构信息](https://pmc.ncbi.nlm.nih.gov/articles/PMC8976135/)。研究涉及葡萄糖、乳糖、麦芽糖等，方法为透射 THz-TDS，论文讨论 0.1–2.5 THz。

- 固态原始数据 ZIP：38.1 KB，官方预览列出 12 个 TXT，含 `ref-1w.txt`、`ref-2w.txt`。
- 液态原始数据 ZIP：42.2 KB，预览列出 14 个 TXT，含 `ref shui-1w.txt`、`ref lvzhi-1w.txt` 等参考文件。
- 仓储还列出 CIF／XSD 晶体结构或模拟文件；这些不能算作实测光谱样本。

**核验范围是 ZIP 文件名和成员目录，TXT 数值及时间单位没有读取。** 26 个 TXT 含参考信号和不同物质／状态，不是 26 个独立植物样品。适合验证参考信号匹配、FFT 和吸收谱处理，不适合直接开展药材产地分类。当前可读页面未明确给出数据许可，不能将论文许可自动套给数据；再分发原始文件前需核对。

### 4. 水稻籽粒：有公开压缩包，内部格式待查

[Rice seed dataset V3](https://data.mendeley.com/datasets/wj2h5hn7kc/3)，DOI：`10.17632/wj2h5hn7kc.3`。官方[版本比较页](https://data.mendeley.com/datasets/compare/wj2h5hn7kc)列出 `Data in Brief.zip`，8.34 MB，CC BY 4.0，描述为水稻饱满度太赫兹光谱及成像数据。

[关联论文](https://doi.org/10.1007/s10762-023-00922-5)作者涉及华东交通大学、浙江大学，使用光谱图像区域识别。**目前只确认外层 ZIP，内部数值格式、THz-TDS 采集模式、参考波形及标签编码没有核验。** 论文数据声明与单独公开仓储之间的完整对应关系也待核对。该数据更接近种子检测，但标签不是生长产地，图像像素不能直接算作独立籽粒。

### 5. 河南工业大学等：转基因玉米含量 THz 数据，仓储待核验

[2026 年论文](https://doi.org/10.1038/s41538-026-00866-9)指向 [Zenodo DOI](https://doi.org/10.5281/zenodo.19150796)。论文描述 6 个含量水平、1080 片压片，排除 6 片后为 1074 片；吸收系数分析为 0.2–1.2 THz、121 点。

**这些数量来自论文，并非已读取仓储数组。** 本轮未取得仓储文件清单或许可，不能列为已验证可下载的数据。用途若核验成立应是含量回归；原始时域是否入库、独立配制批次及重复测量关系仍待查。

### 6. 国家基础学科公共科学数据中心：煤岩 THz-TDS

[官方数据页](https://nbsdc.cn/general/dataDetail?id=6193512499f1de45b82074b8&type=1)由中国矿业大学相关团队提供，列有约 6.81 MB ZIP 和 26.07 KB DOCX。介绍涉及煤岩时域信号及频谱、n、α、介电参数等处理用途。

本轮详情访问显示登录／权限限制；内部文件、频段及标签未读取，是否还需额外申请未知。**这是国家平台中的真实 THz 数据线索，但对象是煤岩。** 只能作为物理处理和技术流程候选，不能回答植物或中药产地问题。

## 获取后的研究顺序

1. **人参 2025 候选包已由用户上传并解析。** 原件哈希、文件清单、频轴与 n／α 已保存；下一步核对压片、原植物、批次及重复关系，再建立按样品分组的分类基准。2026 来源先做重叠检查，不能直接扩充样本量。
2. **再取 Dryad 小麦粉数据。** 确认 X／Y 方向、频率及浓度单位和样品划分，对比老师的 BP、PLS、SVM／SVR 与 CARS／UVE。报告新的实际运行指标，不能把论文准确率当成复现结果。
3. **取首师大或剑桥原始时域数据。** 核对参考、厚度、时间零点、窗口、相位展开和有效频段，验证生成频域及 n／α 的处理过程。这属于信号处理验证，不是产地模型泛化验证。
4. **回到自有酸枣仁数据开展主实验。** 用户已确认相关地名指生长地，仍需把具体文件／谱列与唯一产地、独立样品及批次对应。少样本校准应在有可信样品关系的目标批次／地区上评价，不能拿其他物种的标签充当酸枣仁新产地。

导入时统一检查 Hz／THz、时间单位、cm⁻¹／m⁻¹、厚度单位、PE 或其他参考条件；只在可信的共同频段比较。参考谱、重复谱、同一压片的像素及预先导出的交叉验证文件不能重复计作独立样本。数据驱动预处理和变量选择在训练折内拟合。
