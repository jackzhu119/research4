# 按用户顺序执行的四轮嵌套优化

2026-10-31。依据用户指定的MC-UVE→SVM→预处理→稳定组合／CNN对照顺序，先记录[总计划](../data/research/staged_nested_plan_20261031.json)，由核心与组合两个运行协议落实。当前所有855份样品和原频率范围0.1—1.5的612点均不改。

本轮回到原**5外折／2内折**，分区seed20261031、模型seed42、CARS内部2折。复用原855样品OOF分区，每外折684训练／171测试，内层342／342，ZY02外层训练4份、内层训练2份。原513／171／171派生分组保持原样，属于另一项实验，本轮不将两种成绩混合排名。

## 先精确复算90.41%参考

用户提供的MC20参数核对无误：20次MC、2个PLS潜变量、保留`ceil(.1×612)=62`点。但是90.41%还包括内层选择Raw／SNV及C＝0.1／1／10／100，gamma为scale、类别权重balanced。原五折均选SNV，C为100／10／100／10／100，最终773／855正确。

因此另设R0复算这8个候选，并保留SNV／C10固定锚定。SVC必须保持原`predict`投票规则；原MC20换成OVR分数argmax会少对1份，不能用改变判别规则制造参数收益。

## 四轮逐一改变什么

| 轮次 | 内层候选 | 固定／继承内容 |
| --- | --- | --- |
| R1 MC-UVE | MC10／20／50 × PLS1／2／3 × 保留5／10／15／20%，36组 | 固定SNV、C10、gamma scale、balanced |
| R2 SVM | 6个C × 4种gamma规则 × 4种权重，96组 | 继承**当前外折**R1的MC设置，保持SNV |
| R3 预处理 | Raw、SNV、SG0／1／2阶＋SNV、MSC、线性去趋势＋SNV，7组 | 继承当前外折R1及R2；特别保留SG一阶＋SNV诊断 |
| R4 组合对照 | 普通MC、10倍MC预算、稳定MC、稳定CARS、MC／CARS联合、CNN原头、CNN特征＋SVM，7组 | 继承当前外折R1／2／3；所有新训练仍只用内层源样品 |

保留比例向上取整为31／62／92／123点。MC-UVE使用现有one-hot多分类PLS系数稳定性，产地编号不当作连续含量。10／20／50次可共用一个50次系数路径，但必须分别按自己的前缀重算均值、样本标准差及稳定性floor，并验证与独立拟合相同。

SVM的C为0.01／0.1／1／10／100／1000；gamma为scale、auto、源scale的0.1倍／10倍。实际数值在当前变换及筛选后的训练矩阵上计算。标准化后非恒定变量方差约1，scale和auto常等价，应记录别名而不宣称四种独立机制。

类别权重采用none、balanced，以及源频率反比权重的0.5／1.5次幂，按当前训练样品平均权重归一为1；仅在内层选择，不自由拟合七个稀少类别权重，也不使用外层测试类别频数。SG窗口15、三阶多项式，导数用原频率间隔；MSC参考仅取当前训练均值。

## 稳定性和自动特征怎样比较

稳定三条路径共用10份源分层80%不放回重采样，每类至少2份，保持CARS内部2折可行。各自按MC频率、CARS频率或二者等权联合频率选同样K点，平频用全源MC排名；不足频率支持而补位的点数显式记录。入选频率和Jaccard只是训练重采样诊断，不等于跨批次稳定或化学峰归属。

10倍MC预算对照用于区分“更多系数采样”与“重采样聚合”。CARS额外计算并不与普通MC严格等FLOPs，记录实际预算，不把增加重复次数本身当作创新。

固定小1D-CNN：8／16通道、GroupNorm、16段池化、32维表示、200轮Adam训练。每个内层训练区都重新训练，不能复用曾见外测样品的旧权重。CNN原分类头与同一编码器的32维特征＋SVM分别保留；特征缩放及SVM只拟合当前源样品。固定架构／预算，不根据内外验证早停。该对照检验当前实现，不推断所有CNN方法的表现。

## 防止逐轮接触外层测试

**每个外折独立选择自己的四轮参数。** 不能将五个外折内层成绩汇总出一个全局参数再回填外折，因为其他外折的训练样品含本外折测试标签。每次预处理、缩放、变量选择、CNN和SVM只在当前内层训练样品拟合。

每个外折按R1→R2→R3→R4继承本折的内层选择，以平均宏F1为主，辅助平衡准确率与准确率，平分按事先规则处理。序贯搜索不是穷举所有组合，不声称已经找到全局联合最优；重复使用内层折可能使内层分数乐观，因此外层负责评价整个搜索策略。

核心五折R0—3和组合五折R4的选择锁、源码及协议全部齐后，统一写入`outer_evaluation_release.json`，才拟合各外层684份并评价相应171份。R0／固定锚／各轮选择策略及预先指定诊断都拼接全部855份OOF预测后计算指标，不能挑最好外折、最好参数或最好种子。外层结果不回头改变下一轮格点。

## 结论范围

855份数据和旧外层结果此前已曝光，本轮仍是回顾性同批次嵌套内部验证，不是独立确认。ZY02仅5份，逐类精确率、召回率及错误样品均需单列；不删类或用复制、SMOTE增加独立样品数。

用户长期方向C需要真正独立新批次。当前每产地仍只有一批，因此不生成真实跨批次准确率、不将随机折或七个文件伪装成七个批次。Gaussian仍不纳入主线。
