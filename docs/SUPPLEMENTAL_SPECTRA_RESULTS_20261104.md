# 补充光谱实验与独立审计结果

状态：**DONE，实际训练、冻结预测、独立评分和原生模型重放均已完成。** 文件日期沿用注册协议；实际开始、结束时间见 UTC 日志。研究分支为 `research/supplemental-spectra-20261104`，未合并 main。

本轮的酸枣仁主候选为 **SG一阶导数＋SNV＋MC-UVE＋RBF-SVM**。在固定旧171份预测样品上，三种子平均准确率为 **93.1774%**、Macro-F1 **0.915255**、Balanced Accuracy **91.6667%**。同协议普通SNV-SVM为88.8889%，准确率差为 **+4.2885个百分点**，相对提升4.8246%。收缩LDA在这批预测样品上略高，为93.5673%，应如实保留。

历史 **96.0234%／Macro-F1约0.9197** 属于另一内部交叉验证协议。本轮是固定训练／校准／预测拆分，不能把93.18%、95.91%或94.83%直接与96.0234%相减并称为统一基准的提升或退步。

## 论文使用与下一步

酸枣仁MC-UVE优化仍为论文核心，普通SVM、收缩LDA及MLP均作为公平对照保留；不要删除略优的LDA或外部植物上MC-UVE未胜出的结果。当前证据支持特征压缩、同协议基线改善和保守校准避免伤害，尚不支持“全新算法”“跨批次小样本提升”或“新增来源已可靠识别”。

接下来优先补齐ZY02及新增来源的独立样品、同一类别覆盖的独立新批次和仪器／单位／原料元数据，再预注册新的确认评价。黄芪、天麻继续作为独立泛化任务；来源入组与真正跨植物迁移分开描述。DFT机制研究单独继续，不用尚未验证的理论峰位反向调整这些已曝光预测集上的分类器。
