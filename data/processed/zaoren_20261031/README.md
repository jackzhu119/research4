## 文件与核验

- `样本N_编号版.xlsx`：修改后的完整工作簿，未覆盖输入附件。
- `样本N_编号对照.csv`：逐表逐单元格的旧名称、新名称和基础编号。
- `酸枣仁_编号对照表.xlsx`：汇总、855条唯一编号及3420处表头对照。
- `编号核验.json`：来源和输出SHA-256、数量及内容保留检查。
- `导入记录.json`：本轮上传ID、已保存的原始文件位置及全部7份工作簿的完成状态。
- `分卷恢复记录.json`：样本1的3个分卷SHA-256、上传ID、恢复的原始文件大小及SHA-256。

修改发生在XLSX包内的第一行样本名称单元格；坐标／参考表头、第一行之外全部XML以及其他包成员逐字节不变。另以独立读取方式核验四表对应、跨文件唯一性、ZIP完整性及openpyxl可读性。已有五份原始文件与本轮附件SHA-256完全一致，原始归档沿用；新增样本1、4另存于原始数据目录，路径见导入记录。

## 样本1的补处理

首次样本1附件超过工具32 MiB传输上限。用户补传全部3个RAR分卷后，使用系统libarchive的`archive_read_open_filenames`按part1、part2、part3顺序读取，成功恢复唯一成员`样本1.xlsx`，大小54,540,804字节，SHA-256为`5c569b7c6be91157ca2a0f738ac7a10d2fdd7b5644b7abbffd6ecdb74354ce90`。恢复的完整原始文件通过XLSX/ZIP CRC检查；四表各350个谱记录，已按ZY01编号，没有替换或合并样本2—7的数据。

仅依赖Python标准库的编号脚本也可在有原文件的电脑上运行：

```bash
python scripts/rename_spectral_headers.py --workbook "ZY01=样本1.xlsx" --output-dir 样本1编号结果
```

脚本只支持明确的第一行“样品N／样本N”表头；遇到同表重复编号或四表编号集合不一致会停止，避免错误配对。所有输出使用新文件名，已有结果不会被覆盖。
