# 酸枣仁三用途拆分衍生文件

实验步骤见[三组协议](../../../docs/ZAOREN_THREEWAY_PROTOCOL.md)，校准前后全部实测结果见[执行报告](../../../docs/ZAOREN_THREEWAY_REPORT.md)，冻结源模型见[模型目录](../../../models/zaoren_threeway_20261031/README.md)。

本目录由当前7份编号版按独立样品拆分生成，不是新增观测，也不替换原始有效工作簿。不要将本目录与原编号版拼接计数；有效来源仍以`data/active_workbooks.json`为准。

- 训练样本专用：只用这些样品选择预处理、特征和模型参数，随后冻结。
- 校准专用：训练冻结后，仅从该池抽取少量有标签样品拟合校准器；不回填预测集。
- 预测专用：同一固定预测集比较校准前后结果；其真值表单独放在`evaluation/prediction_truth.csv`，只用于最终评分。

每个来源各有3份衍生工作簿，共21份；四个谱表保持同一份样品归属。坐标、参考列、选中样品原数值、ZY编号及厚度后缀保留，列位置紧凑排列。保留单元格的XML载荷摘要、文件SHA-256与原件未变校验见`workbook_verification.json`。

固定随机种子为20261101，按类别及记录ID排序后使用NumPy PCG64分配60%训练、20%校准、20%预测。逐样品归属见`split_manifest.csv`，完整规则及来源hash见`split_plan.json`。

ZY02只有5份，拆分为3／1／1，因此全部7类只能统一开展每类1份的校准；不能声称已具备7类3／5／10-shot条件。ID的ZY前缀及文件分组仍透露匿名类别，这些是用途隔离文件而非盲样。模型输入只能包含光谱数值，不能包含文件名、ID或标签列。

用户确认每产地目前仅一批，故这是同批次样品留出实验，不是真实跨批次校准。全部855份数据此前已参与内部交叉验证；此次为回顾性重新划分，不是从未查看的外部确认集。
