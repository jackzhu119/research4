## 任务范围与数据边界

沿用上一轮的算法、主划分和历史代码，不重分原855份样品。这里只物理导出主名单中的999份TRAIN；334份校准池和339份预测样品没有进入后台worker输入。原始18份光谱和上一轮报告、模型、预测均保持不变。

- 经典算法225项：5项任务×α／n／n＋α三种表示×5个训练内外折×3个分区重复。每项继承R0、R2、全谱SVM和PLS-DA的训练内2折选择；融合时分别处理n与α。
- 神经迁移1080项：酸枣仁、黄芪、天麻三个目标×5个训练内外折×3个模型种子×8种编码器／训练／冻结配置×120／480／1920三个预训练步数。
- 每项迁移保留仅目标A、额外目标预训练Aextra、另外两种药材预训练B和同源同128点SVM参考。编码器、SNV和校准实现沿用既有研究。源、每类10份支持池、训练内验证互斥；K＝1／3／5／10从支持池嵌套抽取。相同A／SVM用带hash的缓存复用。
- 共1305项实验，另有13份中途汇总和1份最终汇总，共1319个受预算监督的作业。完整名单、代码hash和CPU授权记录见 [protocol.json](protocol.json)、[jobs.json](jobs.json)及[input_lock.json](input_lock.json)。

各配置只比较训练内开发表现。完整五折及预定种子／支持重复才进入开发推荐；缺折、失败和未启动均单列。使用这些开发分数选择配置仍可能存在选择乐观性，不能把推荐配置的同一开发分数称为独立测试准确率。种子或支持抽样不会增加独立样品数，也没有新增真实批次。

- 每项作业日志：`control/logs/`；监督器日志：`control/supervisor.log`。

所有后台模型、日志、状态和后续结果默认留在当前工作区，不自动推送公开仓库。受控代码、计划和输入来源可以复核。

正常暂停后的预算保持式恢复命令（先用status确认没有监督器在运行）：

```bash
nohup python scripts/species_background_budget.py resume \
  --manifest data/research/species_background_20261108/jobs.json \
  --state-dir data/research/species_background_20261108/control \
  >> data/research/species_background_20261108/control/supervisor.log 2>&1 < /dev/null &
```

不要重新创建state或提高manifest预算来假装续跑；监督器会核验累计CPU、输入、代码、模型结果、日志和进程启动身份。完整单项跳过，部分单项复用已完成阶段；普通任务错误记录并最多重试一次，然后继续其他独立任务。输入或代码漂移会暂停整个队列。

## 资源与存续边界

监督器串行调度，数值库和模型线程固定为1。预算计入监督器本身、已结束子进程及活跃worker／后代实际CPU时间，不将sleep或I/O等待当成CPU秒；逐任务使用剩余预算，不能给每项重新分配90,000秒。另有剩余额度的Linux CPU限制、进程组watchdog及5 CPU秒终止余量。普通Linux用户进程无法保证群组在最后一个CPU tick恰好停止，因此实际用量与停止原因均保存。

进程与聊天回复分离，在云环境保持运行时继续执行。若平台关闭或回收环境，无法保证计算进程继续；检查点保存在当前工作区。正常暂停可直接核验后恢复；监督器被强制杀死等异常退出会先阻止自动重置额度，核对原worker和预算后再恢复。

启动前25项回归测试、366项神经边界自检和两个真实worker的完整／部分恢复与hash检查已通过。工程测试验证执行边界，不代表新的科学性能结果。
